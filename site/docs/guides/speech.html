语音 ​

文字转语音、语音转文字、换音、音色库与音乐库。

侧栏「语音」有文字转语音、语音转文字、换音三项；音色库和音乐库在「资源」下。语音是独立 Provider，不在 LiberAstra 进程内。本机 Liber Speech 从「设置 → 插件」安装并启用；已经跑在别的机器上时，到服务提供方填地址。详见 作品与任务 → 插件。

文字转语音 ​

按服务类型出不同控件：

配音服务音色怎么选试听
本地 TTS（edge_tts）服务音色列表，例如 zh-CN-XiaoxiaoNeural有
API TTS（OpenAI 兼容）服务音色列表，例如 alloy有
Liber Speech音色库或「使用默认声音…」，并选择语言无。克隆音色直接播放音色库里的参考音频
ComfyUI 语音工作流工作流包参数无

试听出现在文字转语音、数字人口播、快速创作和自定义素材。输入框默认是「你好,这是一段试听语音! 」，也可以改成别的短句（最多 200 字）。点喇叭用当前音色当场合成并播放，不进入任务队列，也不保存成资产。

Liber Speech 的模型在「系统设置 → 语音文字合成（Liber Speech）」里选择，默认文字转语音模型 multilingual_v3（Chatterbox-Multilingual V3）。功能页还可以再选具体模型，留空时使用系统设置；模型列表从已启用的 Liber Speech 读取，并按模型系列分组。语言下拉跟随当前文字转语音模型：多语言模型列出 23 种语言，单语言包只保留那一种。选音色库条目时，参考音频用来克隆音色，语言只决定 language_id。选「使用默认声音…」时不传参考音频。朗读语言只影响发音，不翻译正文。Turbo 和 Nano 只读英文，克隆参考音频需要长于 5 秒。

语音转文字 ​

上传音/视频（也可以点「从资源库选择」挑已有文件），选识别服务、识别模型和语言。语言可自动或 zh/en 等，其他语种选自定义后填代码。模型留空时用「系统设置 → 语音文字合成」里的语音转文字模型；OpenAI 兼容服务留空则用它自己的默认模型（例如 whisper-1）。输出按 txt、json、srt、vtt 取第一种可用。

换音 ​

上传音频或视频，选择音色库里有参考音频的音色，保持说话时间轴不变，只替换音色。输出音频（mp3 / wav 可选）、srt / vtt 字幕；视频输入还可以替换音轨或烧录字幕。

  • 字幕：默认自动识别；也可以上传 srt 跳过识别。没有被字幕覆盖的区间会保留原声，任务结果里会记录覆盖率。
  • 分离背景音：先拆人声和伴奏，只换人声再混回去；语音服务未装 Demucs 时开关会禁用。
  • 视频输入：可以烧录字幕，字号和颜色可调；字号 0 表示按视频高度自动。
  • 限制：素材不超过 200MB / 30 分钟；多人说话会统一换成同一个目标音色。
  • 模型：默认 Chatterbox VC；系统设置可以改默认模型，也可以在页面选 Seed-VC。

画布里的「音色替换」节点和这个页面共用同一套任务。节点可以连音频或视频，默认自动识别字幕；属性面板可上传 srt、开启烧录、调字号颜色。输入音频时输出音频，输入视频时输出视频（音频和字幕作为附带产物）。快捷菜单里的「音色替换」由「画布菜单设置」决定，可以改名、禁用或改绑定。

音色库 ​

侧栏「资源 → 音色库」。本地克隆：上传参考音频 + 参考文字，voice_id 留空。仅云端复刻返回编号时才填 voice_id。

音乐库 ​

侧栏「资源 → 音乐库」。BGM 上传/试听/删除；同名自动加序号。快速创作与自定义素材从这里选。

相关：语音模型和默认服务在 设置 → 系统设置；画布上的语音节点和「音色替换」节点见 画布与导演台。
