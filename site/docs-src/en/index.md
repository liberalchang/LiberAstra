# LiberAstra orchestration desk

LiberAstra is a self-hosted AIGC orchestration desk. It connects ComfyUI, Ollama, speech services, and an OpenAI-compatible `/v1` endpoint into one place.

- Access: Web UI, `astra` CLI, MCP, OpenAI-compatible `/v1`
- Important: LiberAstra does not run models; providers do
