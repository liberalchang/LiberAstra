## 文生图

侧栏打开「图像 → 文生图」。图像服务选已保存的 ComfyUI，工作流包选 `qwen_image_21`。

这次测通的 ComfyUI 地址是 `http://10.10.12.140:8188`。换机器时只改 Base URL，工作流包名不变。

### 先配好 ComfyUI

1. 打开「设置 → 服务提供方」。
2. 类型选 ComfyUI。
3. 名称自定。当前这台用的名称是 `comfy`。
4. Base URL 填 `http://10.10.12.140:8188`。这个端口是 HTTP。写成 `https://` 时浏览器会报协议错误，服务起不来。
5. API Key 留空。
6. 保存。列表里应能看到这一条。

模型文件名写在工作流包里，文生图页面不用再填 `ckpt_name`。这台机器上对应的文件是：

| 用途 | 文件名 |
| --- | --- |
| UNET | `qwen_image_2.1_int8_convrot.safetensors` |
| 文本编码器 | `qwen3vl_8b_int8_convrot.safetensors`（加载类型 `qwen_image`） |
| VAE | `qwen_image_2.1_vae_bf16.safetensors` |

内置包 `t2i_basic` 要从 ComfyUI 的 checkpoints 目录读一个大模型。这台机器该目录是空的，文生图请用 `qwen_image_21`。

`qwen_image_21` 随项目放在 `backend/workflows/qwen_image_21`。若 `backend/data/workflows` 里有同名包，实际用的是那一份，内置包会被盖住。

### 页面上怎么填

| 项 | 怎么填 |
| --- | --- |
| 图像服务 | 选上面保存的 ComfyUI |
| 工作流包 | `qwen_image_21` |
| 提示词 | 要画的内容。右侧按钮会用已配置的 LLM 改写这段文字 |
| 负面提示词 | 可留空 |
| 宽度、高度 | 默认 1024，单位像素 |
| 步数 | 页面默认 20。工作流包里写的是 25，提交时以页面上的数字为准。想要更细的画面，可以把步数调高，边长调到约 1416 |
| 种子 | `-1` 表示每次随机。一次出多张时，从这颗种子起逐张加 1 |
| 张数 | 1 到 4。同一次 ComfyUI 任务出多张 |

CFG 固定为 1，写在工作流里，页面上没有这一项。

填好提示词后点「生成」。任务进行时按钮显示百分比。

### 换页之后进度还在

生成时切到别的功能页，后端任务不会停。回到「文生图」，同一个浏览器标签会继续显示这次任务的进度。关掉这个标签后，页面不再自动挂上进度条，任务本身仍在。

「任务」页可以查看状态。成功的图在「资产」。

### 图和配置存在哪

后端从 `backend` 目录启动时：

- 数据库：`backend/data/liberastra.db`。账号、服务提供方、任务、资产索引在这里。
- 生成的文件：`backend/data/outputs/`。
- 上传的文件：`backend/data/uploads/`。

资产在界面上是一条数据库记录加上磁盘上的文件。`backend/data` 若放在网盘同步目录里，数据库可能读写失败。生成时让这个目录不要被同步软件占用。
