# 视频

快速创作、数字人口播、图生视频、动作迁移、自定义素材。角色库在「资源」下，分镜模板在「设置」下。

侧栏顺序：**快速创作** → **数字人口播** → **图生视频** → **动作迁移** → **自定义素材**。

## 选包与模型

### 各页要选什么包

| 侧栏功能 | 页面相关下拉 | 包能力 | 仓库现状（内置） |
|----------|--------------|--------|------------------|
| 快速创作 · 生成插图 | 插图服务 + 插图工作流 | `t2i` | `qwen_image_21` / `qwen_image_21_uncensored`、`flux3_klein`、`t2i_basic` |
| 快速创作 · 生成视频 | 视频服务 + 视频工作流 | 默认 `t2v`；选了角色后也可选 `i2v` | `minimax_h3_t2v`（官方）、`minimax_h3_t2v_uncensored`（越狱无增强）、`minimax_h3_t2v_enhancer`（越狱+增强）；选角色后另见 `i2v` 系列（首帧、多参考、环绕；长视频 Extender 主要留给导演台） |
| 数字人口播 | 视频服务 + 包；另选配音 | `avatar` 等 | `minimax_h3_avatar` / `minimax_h3_avatar_uncensored` |
| 图生视频 | 视频服务 + 工作流包 | `i2v` | `minimax_h3_i2v`（首帧；包内另有可选尾帧槽）/ `minimax_h3_i2v_uncensored` / `minimax_h3_i2v_enhancer`；另有 `minimax_h3_i2v_ref`（多参考）、`minimax_h3_orbit`（360° 环绕）、`minimax_h3_extender`（长视频，主要由导演台使用） |
| 动作迁移 | 视频服务 + 工作流包 | `motion` 等 | `minimax_h3_motion` / `minimax_h3_motion_uncensored` |
| 自定义素材 · 素材动画 | 动画服务 + 动画工作流 | `i2v` | `minimax_h3_i2v` / `minimax_h3_i2v_uncensored` / `minimax_h3_i2v_enhancer` 等 `i2v` 包 |
| 自定义素材 · 看素材写文案 | 分析服务 + 分析工作流 | `analysis` | `analysis_image_qwenvl` / `analysis_video_qwenvl` |
| 角色库 · 按描述生成 | 不在本页选。用「系统设置 → 默认角色生图」 | `t2i` / `i2i` | 分别选文生图、单张参考图、多张参考图三个包；默认 `qwen_image_21`、`qwen_image_21_edit`、`qwen_image_21_edit_multi` |

侧栏「工具 → 视频增强」是单独页面，选视频服务和 `v2v` 工作流包（内置 `seedvr2_3b_video_restore`），不依赖上表的视频生成页面。

### 页面上怎么选（通用）

1. **视频 / 插图 / 动画服务**：已启用且能力匹配的 Provider。选 ComfyUI 后，模型列表从该机 `/models/...` 拉取。
2. **工作流包**：按上表能力过滤。下拉里先显示能力名和包的短标签（`summary`），越狱包会标「越狱版」；右侧灯泡弹出完整说明。选中后：
   - 包声明但磁盘缺失的模型 → 黄字警告（不拦截提交）。
   - 展开参数：主模型、文本编码器、VAE、LoRA 等。
   - 包有 `accel` → **Turbo 加速**或 **Uncensored LoRA** 开关。MiniMax H3 的 Turbo 带采样预设：打开把步数、采样器改成 8 步、`euler`，关闭改回该包自己的默认值；这两项里已经填过的值也会被覆盖。图像越狱 LoRA 没有步数预设，开关只挂上或摘掉 LoRA。目前 MiniMax H3 视频、数字人、动作迁移和 Qwen 图像编辑包默认开启加速；需要对比质量时可在参数里关闭。
3. **宽高 / 时长**：图生视频用宽高比，按包 `multiple` 吸附（H3 常为 32）。有 `fps` 的包按「秒」设时长，提交换算帧数并按 `align_base`/`align_offset` 吸附（H3 为 17k+5）。数字人口播不显示时长，画面跟着配音走。
4. H3 / 长任务：建议「设置 → 系统设置 → 运行参数」里 **ComfyUI 等待超时** ≥ 3600 秒。

### MiniMax H3：版本 = 成套文件（不要混搭）

Comfy 上同一「功能」往往对应**多份文件**。界面下拉可以单独换文件名，但**官方 / 越狱 / 量化规格要成套选**，否则容易加载失败或效果异常。

#### 共用（官方与越狱都要用）

| 角色 | 目录 | 当前推荐文件（远程常见） |
|------|------|--------------------------|
| 主模型 FL2VA（首帧/首尾帧、文生视频） | `diffusion_models/` | `minimax_h3_fl2va_pruned_int8_convrot.safetensors` |
| 主模型 Ref2VA（参考图/参考视频、长视频） | `diffusion_models/` | `minimax_h3_ref2va_pruned_int8_convrot.safetensors` |
| 视频 VAE | `vae/` | `minimax_h3_video_vae_fp16.safetensors` |
| 音频 VAE | `vae/` | `minimax_h3_audio_vae_fp32.safetensors` |
| Turbo LoRA（可选） | `loras/` | `minimax_h3_turbo_v4_step600_ema.safetensors`。节点是 `MiniMaxH3TurboLoRA`（需安装 [Larryvrh/ComfyUI-MiniMax-H3-Turbo](https://github.com/Larryvrh/ComfyUI-MiniMax-H3-Turbo)）；调度器保持 `simple`。下拉只列出文件名含 `_ema` 的权重 |

FL2VA 和 Ref2VA 是两套权重，不要在同一条工作流里混用：`minimax_h3_i2v`、`minimax_h3_orbit`、`minimax_h3_t2v`、数字人用 FL2VA；`minimax_h3_i2v_ref`、`minimax_h3_motion`、`minimax_h3_extender` 用 Ref2VA。`minimax_h3_orbit` 默认视频 VAE 是 `minimax_h3_video_vae_int8_convrot.safetensors`，其它 H3 包默认 fp16；它另用 `loras/minimax_h3_flf2v_lora_v1.safetensors`（首尾帧环绕 LoRA），不是 Turbo。换主模型时整条链路仍用同一套 VAE。其它量化（未剪枝 INT8、FP8、W6A8 等）体积不同，不要混搭。

> RTX 3090 / Ampere 建议用 Comfy-Org 的 `minimax_h3_ref2va_pruned_int8_convrot.safetensors`（约 21GB）。社区 NVFP4 权重面向 Blackwell；非 Blackwell 卡上 NVFP4 走模拟，不保证速度和兼容性。

#### 文本侧：官方套餐 vs 越狱套餐

| 套餐 | 文本编码器（TE，`text_encoders/`） | 生成尾（tail，仅提示词增强需要） | 对应内置包 |
|------|-------------------------------------|----------------------------------|------------|
| **官方** | `qwen3vl_32b_minimax_h3_nvfp4_awq.safetensors` | 一般不需要；若官方增强需同族 `…instruct_generation_tail…` | `minimax_h3_i2v` / `minimax_h3_t2v` |
| **越狱 NVFP4（无增强）** | `qwen3vl_32b_heretic_minimax_h3_nvfp4.safetensors` | 不需要 | `minimax_h3_t2v_uncensored` / `minimax_h3_i2v_uncensored` |
| **越狱 INT8 + 增强** | `qwen3vl_32b_h3_ultra_uncensored_heretic_int8_convrot.safetensors` | `qwen3vl_32b_h3_generation_tail_50_63_int8_convrot.safetensors` | `minimax_h3_i2v_enhancer` / `minimax_h3_t2v_enhancer` |

配对规则：

- **TE 与 tail 必须同族**（官方配 instruct tail，越狱配 heretic 配套 tail）。
- `CLIPLoader` 的 type 均为 `minimax`；换文件不等于换节点类型。
- 在 `minimax_h3_i2v` 里只把 TE 下拉换成越狱文件 = **不增强提示词的越狱出片**（仍可不装 Guide）。要「看图改写提示词」必须用 enhancer 包，并装 [Guide 节点包](https://github.com/ethanfel/ComfyUI-MiniMax-H3-Guide)。

#### 量化怎么理解

同一角色常有多种量化文件（如 TE 的 nvfp4 / int8_convrot / bf16）。**选一个规格用到底**，不要主模型用 pruned-int8、TE 却随便混一个未验证组合。3090 上官方 nvfp4 可跑但非最快；越狱 TE（约 25G）更吃内存，远程 62G 机器上建议单独观察是否 OOM。

更细的文件清单与下载地址见 [模型相关资源](/models)。

## 其他生成方式

### 自定义素材

已有图片或视频，配口播和字幕，按上传顺序拼成一条短片。画面默认保持原样。

页面从上到下是：素材 → 文案与标题 → 素材动画 → 配音 → 画幅、字幕与背景音乐。打开素材动画或上传了视频时，配音可以改成「模型原声」，保留动画或视频自带的音轨。点「开始合成」后的顺序是：文案已经定好 → 有标题则先做 2 秒标题卡（不烧字幕）→ 自定义配音时逐段合成并写字幕，模型原声时按片段自身时长写字幕 → 图片按开关保持静止或做动画 → 拼成一条 → 有背景音乐再混入。

#### 素材

顺序就是分镜顺序，可多次添加，也可以点「从资源库选择」挑已有图片或视频。每一段视频会循环或截断到这句配音的时长。

#### 文案与标题

标题选填。填写后，片头是一张 2 秒标题卡。

文案三选一，互不影响：

| 选项 | 怎么得到口播 | 看不看画面 |
|------|----------------|------------|
| 自备文案（按行对应素材） | 自己写。每行一句，对应素材顺序；行数不够会循环使用 | 不看 |
| 主题生成文案 | 只填主题和目标时长。按文件名、视频时长写口播。需要「系统设置」里的默认 LLM | 不看 |
| 看素材写文案 | 上传素材后点「生成文案」。视觉模型先看每张图、每段视频，再写成口播。生成后可以改，出片用的就是这段文字 | 只在点「生成文案」时看一次 |

看素材写文案还要选：

- **分析服务**：执行分析的 ComfyUI。
- **图片分析工作流**：有图片时必选。内置 `analysis_image_qwenvl`，需要 ComfyUI-AILab 和 Qwen-VL（默认 Qwen3-VL-8B-Instruct）。
- **视频分析工作流**：有视频时必选。内置 `analysis_video_qwenvl`，还需要 Video Helper Suite 抽帧。
- **补充要求**、**目标时长**：选填。用来指定语气、卖点和句子长短。留空就只按画面写。

没上传素材时「生成文案」不可用。这段口播为空时不能开始合成。

#### 素材动画

开关默认关闭。打开后，只在「开始合成」里、这一段配音完成之后生效：每张静图单独走一次 `i2v`，生成一小段运动画面，再循环或截断到这句配音的时长，然后配上字幕。

上传的视频和标题卡保持原样。当前素材里没有图片时，开关不可用。

动画提示词留空时，默认轻微、自然的镜头前推。填写后使用你写的运动描述。工作流选 `i2v` 包，例如 `minimax_h3_i2v`、`minimax_h3_i2v_uncensored`、`minimax_h3_i2v_enhancer`；多参考和环绕包也可以选，按各自的图片槽送图。包有 `accel` 时可开 Turbo。每张图一次图生视频，张数越多越慢。

#### 配音、画幅与背景音乐

配音按素材逐段合成，字幕时长跟这句配音走。可以关闭烧录，也可以改字幕字号和颜色：字号 0 为自动，颜色默认白色。标题卡不烧字幕。配音服务是 ComfyUI 时要另选语音工作流，口播文本自动注入。本地 TTS 或 API TTS 可以在音色下面试听，见 [文字转语音](/guides/speech#文字转语音)。画幅为 9:16、1:1 或 16:9。背景音乐从音乐库选择，在全片拼完之后混入。

选了「模型原声」并且动画工作流支持参考音频时，配音区会出现「音频连续性（实验）」：

- **模型原生**：不额外处理，保持当前行为。
- **上一镜尾音**：从上一张动画的音频末尾取 2–15 秒作为下一镜参考；第 1 镜没有参考。
- **全片氛围底**：从音乐库选择或上传一段音频，按每镜实际时长切片送给 H3；床长不足时可循环或补静音。成片混音可选「bed 为主，模型环境音低音量混入」或「只用 bed 覆盖」。
- 接缝淡化只作用于音乐/环境音，默认 60 毫秒；和成片背景音乐是两层，建议只保留一层。
- 自定义配音、没有参考音频输入的工作流不显示这个控件。

### 数字人口播

人物图 + 口播文案 → TTS 语音 → `avatar` 工作流包。内置两套基于 MiniMax H3 音画联合模型的口播工作流（无需额外安装嘴型插件或音频编码器）：

| 包名 | 默认文本侧 | 原理与特点 |
|------|------------|------------|
| `minimax_h3_avatar` | 官方 TE | `MiniMaxH3ImageToVideo` 锁定首帧人物，`MiniMaxH3AddGuide` 在第 0 帧锚定 TTS 语音潜变量驱动口型与表情，成片直接合成清晰 TTS 原声；可开 Turbo |
| `minimax_h3_avatar_uncensored` | 越狱 **NVFP4** TE | 同上，默认使用越狱文本编码器；可开 Turbo |

另选配音服务与音色。画面时长由这段配音决定，页面上不再手填秒数：帧数按 `17k+5` 向上取整后再裁回配音长度，只多留约一帧。估算超过约 12 秒、或合成后仍超过单段上限（362 帧，约 15 秒）时，按句子切开，下一段用上一段尾帧当首帧，最后合成一条视频。后面各段不再回到角色定妆照，段数很多时人物仍可能慢慢跑偏。成片之后可以再从音乐库叠一条背景音乐。本地 TTS 或 API TTS 可以在音色下面试听，见 [文字转语音](/guides/speech#文字转语音)。

人物图可以上传、点「从资源库选择」，也可以从角色库选择。选了角色时，**只有第一段**用角色的**面部半身特写**（9:16 四宫格切出的单人图）当首帧，不用全身图，也不用整张设定图。上传的图片优先于角色库。角色若绑定了音色，配音没另选时会带上。

### 图生视频

首帧 + 提示词 → `i2v`。页面按工作流包声明的图片槽逐个显示：首帧必填，可选尾帧、侧面/背面参考、额外参考图都会出现在「更多图片」里。成片保留模型自己生成的音轨，也可以再从音乐库叠一条背景音乐。

| 包名 | 默认文本侧 | 特点 |
|------|------------|------|
| `minimax_h3_i2v` | 官方 TE | 首帧必填；可选尾帧槽 `last_frame` 在页面「更多图片」里上传；提示词原样进生成；可 Turbo |
| `minimax_h3_i2v_uncensored` | 越狱 **NVFP4** TE | **越狱、无增强**；首帧必填，可选尾帧；默认 LightX2V 8-step；可 Turbo |
| `minimax_h3_i2v_enhancer` | 越狱 INT8 TE + tail | 首帧必填，可选尾帧；先 Guide 增强再出片；结果区可看增强文本；可 Turbo；需 Guide |
| `minimax_h3_i2v_ref` | 官方 TE | 最多 9 张参考图，页面按槽位全部显示；图片只提供外观，不当作视频第一帧；提示词用 `<Picture N>` 指代；可 Turbo |
| `minimax_h3_orbit` | 官方 TE | 360° 环绕镜头；一张图时首尾都用这张，页面再传第二张可作为结束画面；提示词留空使用内置环绕句，两张不同图且提示词仍是原句时会自动加换装句；默认 73 帧（约 3 秒）、28 步，不需要 Turbo |
| `minimax_h3_extender` | 官方 TE | 长视频 Extender：用 `clips_json` 描述每段时长和提示词，参考图通过 `ref_1`～`ref_9` 传入，每段不超过 15 秒；主要由导演台生成 |

enhancer 更慢、更吃内存；适合提示词很短或希望先改写成 H3 规范长提示词的场景。`i2v_ref` 的参考图不是首帧，适合先给人物、服装和场景参考，让模型自己决定镜头起点。`orbit` 适合人物、产品原地环绕；镜头和人物都保持不动时效果最稳，场景里有大量运动物体时容易漂移。

选了角色库里的角色后，再选这一镜的入镜视角：面部半身特写、正面全身、侧面全身或背面全身。页面会把角色图补进还空着的参考槽，用户上传的图片优先。多参考包按槽位顺序解锁：填了 `image_2` 才能填 `image_3`，清空前面的槽会一起清掉后面的槽，避免 `<Picture N>` 编号错位。`orbit` 的结束画面、`i2v` 的尾帧也在同一块「更多图片」里上传。近景用特写，全身动作用对应全身图。快速创作可以让不同分镜轮换视角，从而用上多张定妆图。图片可以上传或从资源库选择，上传的图片优先于角色库。

#### 图生视频的音频参考（H3）

`minimax_h3_i2v_ref` 和 `minimax_h3_extender` 在「音频」块提供参考音频：

- `minimax_h3_i2v_ref`：可选「参考音频」，给模型参考环境音/音乐，用于保持氛围一致。是参考不是音频锁定；单条任务不提供“上一镜尾音/全片氛围底”。
- `minimax_h3_extender`：「音频续接」可选关闭、音频上下文、参考音频、两者。上下文长度常用 22，44/96 更强但更慢、更占显存；参考音频从音乐库或上传选择。两者同时开启属于高级实验。
- 这些参考不会替换成片后的背景音乐；背景音乐仍在「高级参数 → 背景音乐」里单独设置。两层同时开启可能重复音乐。

### 动作迁移

参考视频 + 目标图 + 提示词 → `motion` 工作流包。参考视频可以上传或从资源库选择。画面时长跟随参考视频，页面上不再手填秒数。参考视频按动作迁移包的 `length.max` 切开（当前两套 H3 动作迁移包是 124 帧，约 5.2 秒，且满足 `17k+5`）；每段都使用同一组目标图，避免上一段尾帧把目标人物带偏，最后拼成一条。声音可以留模型生成的音轨，也可以换成参考视频的整条原声。两种都可以再从音乐库叠背景音乐。内置两套基于 MiniMax H3 多模态参考（`MiniMaxH3ReferenceToVideo`）的动作迁移工作流。选了角色库里的角色后，目标图选项决定实际送图：默认「正面、侧面、背面三张全身图」会把**正面全身、侧面全身、背面全身**分别送进 `<Picture 1>`、`<Picture 2>`、`<Picture 3>`；选「16:9 定妆照」或「9:16 四宫格」时只送对应的**整张设定图**作为 `<Picture 1>`，不会再拆成正/侧/背。右侧面部特写不参与动作迁移，避免下半身服装丢失。目标图可以上传或从资源库选择，上传的图片优先于角色库。页面还会显示包里的侧面、背面参考槽；补传后分别对应 `<Picture 2>`、`<Picture 3>`。另外还有两个可选额外参考槽，按顺序对应 `<Picture 4>`、`<Picture 5>`；不连接会自动断开。

| 包名 | 默认文本侧 | 原理与特点 |
|------|------------|------------|
| `minimax_h3_motion` | 官方 TE | `VHS_LoadVideo` 按 24fps 抽帧作为 `<Video 1>` 动作参考，目标图作为 `<Picture 1>` 身份参考，无需骨骼预处理即可迁移肢体动作与运镜；可开 Turbo |
| `minimax_h3_motion_uncensored` | 越狱 **NVFP4** TE | 同上，默认使用越狱文本编码器；可开 Turbo |

提示词中可用 `<Picture 1>` 指代目标图、`<Video 1>` 指代参考视频；若未写标签或留空，流水线会自动补齐标准动作迁移指令，并明确「图片负责人物身份，视频只提供动作，不要复制视频人物的脸、发型和服装」。也可自行导入 `WanAnimate2ToVideo` 或 `WanSCAILToVideo` 工作流包。

#### 动作迁移提示词示例

节点提示词留空时可以直接用默认指令；如果参考视频里是真人、担心模型沿用视频人物，建议粘贴下面这段，把人物身份明确锁到图片上：

```text
以 <Picture 1>（正面）、<Picture 2>（侧面）、<Picture 3>（背面）为同一个人物的身份参考，始终保持这个人的脸、五官、发型、肤色、体型和服装。<Video 1> 只提供肢体动作、姿态变化和镜头运动，不要复制视频中人物的脸、发型或服装，不要中途换脸或换装。人物动作自然连贯，镜头运动跟随 <Video 1>。
```

如果启用了额外参考槽，在「服装」后面补一句：

```text
；<Picture 4>、<Picture 5> 也是同一个人物的补充参考，身份仍以 <Picture 1> 为准
```

## 快速创作

快速创作负责把口播做成一条短视频。口播是每一镜里要念出来的那一句文字，配音按这句朗读，字幕也写这句。它不是已经做好的视频文件。

一条成片可以有多镜。每一镜先单独做成一小段：这一句交给配音，画面按这一镜的画面提示词来做。全部小段按顺序接起来，需要的话再铺上背景音乐，才是下载到的那一条 mp4。分镜数是 4，就是 4 小段接成 1 条，不是 4 条视频。

页面最上面的「AI 创作」「固定文案」「批量创作」只决定这些口播句子从哪来。下面的分镜模板、配音、字幕、登场角色和背景音乐是三种模式共用的。

### 一条成片里有什么

每一镜有两段文字：

- **口播**：念出来的句子，也是这一镜的字幕。
- **画面提示词**：交给插图或视频工作流的描述。静态模板不用它来生图，文字直接排进版式。

标题是整片共用的一行字，显示在画面上，不会被当成其中一句口播去念。

可以勾选「生成分镜后暂停，人工确认后再合成」。勾上之后先给出脚本和分镜 JSON，改完每一镜的画面提示词再合成。批量创作没有这一项。

### AI 创作

适合还没有写好稿子、只知道要讲什么的时候。填一个主题，再设分镜数（1 到 12，默认 4）。

主题原文会当成视频标题，显示在画面上。系统设置里的默认大语言模型（LLM）按分镜数写口播。分镜数是 4，它就写 4 句，每句大约 20 到 40 个字，口语化。这 4 句对应 4 镜：第 1 句配第 1 段画面，第 2 句配第 2 段画面，四段接成一条。LLM 自己起的标题不用，标题始终是你写的主题。

主题框上的 ✨ 只把你输入的主题扩写得更具体，方便后面写口播。口播要等点「开始创作」之后才由 LLM 写。

模板如果是「生成插图」或「生成视频」，还有「生成时用 LLM 写画面提示词」，默认打开。打开后，4 句口播写完，LLM 再把每一句改写成给画图、给视频看的画面描述。关掉时，画面描述就用口播原文。带 Guide 的工作流包（名字里有 `enhancer`）还会在包内部再改一次提示词；不带的包（例如 `uncensored`）不会。这个包内增强和页面上的开关是两件事，关其中一个不会关掉另一个。

静态样式模板不写画面提示词，口播文字直接排进版式，再配上朗读。

必须已经配置 LLM。没配时页面会提示去系统设置或服务提供方。

### 固定文案

适合稿子已经写好、希望原句被念出来的时候。口播就是你贴进去的文字，系统不会把它改写成别的句子。旁边的主题框只当标题，原样显示，也不经过 AI。

这一页没有分镜数。有多少镜，由「切分方式」决定：

| 切分方式 | 怎样算一镜 |
|----------|------------|
| 按段切分 | 空一行算一段。一段一镜 |
| 按行切分 | 每一行非空文字一镜 |
| 按句切分 | 按句号、问号、叹号切开。一句一镜 |

例如按句切分，文案里有 6 句，就会做出 6 小段再接成 1 条视频。某一段是空的会被丢掉。

静态模板按切分结果朗读并排版。插图或视频模板下，输入框左边是口播，点 ✨ 可以按镜生成画面提示词；开关打开并且右边已经有画面词时，合成直接用这些词，后端不再请 LLM 重写。开关打开但右边还是空的，才由 LLM 按口播补画面词。开关关掉时，画面描述用口播原文。

固定文案在静态模板、或者画面词已经写好时，可以不配置 LLM。

### 批量创作

适合同一个模板、同一种配音，要一次出很多条主题不同的视频。文本框里一行写一个主题，最多 100 行。空行不算。

一行主题对应一条完整视频，同时就是这条视频的标题。它不是一镜。分镜数仍然要设，表示每一条视频内部有几镜，所有主题共用。

例如写了 3 行，分镜数是 4：会排队提交 3 个任务。每个任务都是一次完整的 AI 创作：按这一行主题写 4 句口播，做出 4 段画面，接成 1 条视频。模板、配音、角色、字幕和背景音乐全部共用。单个任务失败不影响其他任务，进度在任务中心查看或取消。批量必须已配置 LLM，也没有「生成分镜后暂停」。

### 画面、声音和字幕

先选画幅（竖屏 9:16、方屏 1:1 或横屏 16:9），再选模板模式，然后选具体模板：

- **静态样式**：本地排版，不调用生图或生视频，也不请 LLM 写画面词。口播文字出现在画面上，再配朗读。
- **生成插图**：每一镜用文生图（text-to-image，`t2i`）工作流出一张图，再和这一句配音合成一小段。
- **生成视频**：每一镜用视频工作流出一小段。默认只列出文生视频（text-to-video，`t2v`）包。选了登场角色后，列表里会再加上图生视频（image-to-video，`i2v`）包：普通 `i2v` 送一张入镜视角图，`i2v_ref` 的包里可接多张参考图（快速创作每镜仍只送当前入镜视角一张；要多参考请用图生视频页或画布），`orbit` 做 360° 环绕；`extender` 是长视频分段包，主要由导演台使用，不建议在快速创作里手选。包声明了加速时可以开 Turbo。名字带 `enhancer` 的包会在包内增强提示词。

配音、字幕和背景音乐在模板下面，三种脚本模式共用：

- 静态模板和插图模板只有自定义配音：按每一句口播合成声音，并替换这一小段的音轨。
- 生成视频还可以选「模型原声」：保留文生视频自己生成的声音，不再换成配音。字幕仍按口播文字、按这一小段的时长来写。
- 配音选本地 TTS（text-to-speech，文字转语音）或 API TTS 时，音色下面可以试听，见 [文字转语音](/guides/speech#文字转语音)。配音服务是 ComfyUI 时要另选语音工作流，口播文本会自动填进去。
- 字幕可以关，也可以改字号和颜色。标题和画面上的口播文字也可以分别隐藏或缩放。
- 背景音乐从音乐库选择，全片接完之后再混入。音量建议 0.1 到 0.3。
- 生成视频并选「模型原声」时，如果所选视频包支持参考音频（例如 `minimax_h3_i2v_ref`），会出现「音频连续性（实验）」：模型原生 / 上一镜尾音 / 全片氛围底。上一镜尾音按顺序生成；全片氛围底会按每镜实际时长切片，不是成片后的背景音乐。成片混音可选「bed 为主，模型环境音低音量混入」或「只用 bed 覆盖」。自定义配音或不支持参考音频的包不显示这个控件。

### 登场角色和入镜视角

角色可以不选。三种脚本模式都能选，批量里所有主题共用同一个角色。

选了之后会发生两件不同的事。

第一件总会发生：角色的外观描述会加在每一镜画面提示词的前面，让各镜在文字上尽量是同一个人。定妆照说明里「16:9 横版、9:16 四宫格、四个视角」这类排版句子会先去掉，避免画面被画成拼图。你在页面上填的风格前缀排在这段外观文字后面。

第二件只在视频包真的有图片输入槽时发生。纯文生视频包没有图片槽，角色图片不会上传。这时「入镜视角」只是写给 LLM 的文字提示，例如当前参考视角是正面，方便它把画面描述写成这个角度。

选了角色之后，可以把视频工作流改成图生视频包。这种包每一镜按视角送一张角色图，用来锁住同一个人：

- 默认用你选的入镜视角：面部半身特写、正面全身、侧面全身或背面全身。
- LLM 写分镜时，可以给某一镜换成另一个视角，从而用上多张定妆图。
- 选「16:9 定妆照」或「9:16 四宫格」则每一镜都送对应的整张设定图，不再拆成单张。
- 这个视角还没有图片、而工作流又要求参考图时，任务会直接失败。

插图模板只把外观写进提示词，不把角色图送进文生图包。

### 文生视频（`t2v`）选哪个包？

| 包名 | 文本侧 | 说明 |
|------|--------|------|
| `minimax_h3_t2v` | 官方 TE | 纯提示词出片；可 Turbo |
| `minimax_h3_t2v_uncensored` | 越狱 **NVFP4** TE | **越狱、无增强**（对应本地画布【文生视频】）；默认 LightX2V 8-step Turbo；可 Turbo |
| `minimax_h3_t2v_enhancer` | 越狱 INT8 TE + tail | **越狱 + 提示词增强**；需 Guide；结果可看增强文本；可 Turbo |

三者都不接首帧。要让每一镜带上角色图，改用 `minimax_h3_i2v` / `minimax_h3_i2v_uncensored` / `minimax_h3_i2v_enhancer`。

## 角色与模板

### 角色库

侧栏「资源 → 角色库」保存一个角色的名称、外观描述、两套定妆照排版和四个单人视角：

- **9:16 四宫格（主产物）**：`1152×2048`，2×2 四格，每格 `576×1024`，仍然是 9:16。左上正面面部半身特写、右上正面全身、左下侧面全身、右下背面全身。系统固定四等分，切成四张 9:16 单人图，分别作为面部特写、正面全身、侧面全身、背面全身。竖屏视频、动作迁移和数字人口播优先使用这四张。
- **16:9 定妆照**：`1536×864`，横版四栏，从左到右正面全身、侧面全身、背面全身、右侧面部半身特写。它在四张 9:16 图之后生成：先把四图拼成 16:9 参考底图，再用多图编辑工作流重绘为原生横版四段。它也用于预览、整图参考和 16:9 图生视频。

整张设定图只用于预览和整图参考，不会被直接当成视频画面；视频默认按镜头取一张 9:16 单人图。16:9 视频如果必须锁首帧，仍建议用 `i2v_ref` 这类“只借外观、不锁首帧”的包，或单独生成一张 16:9 首帧；四张 9:16 视角本身不是 16:9 首帧。

页面上先选一种添加方式，另一种的按钮不会同时出现。

#### 按描述生成

手里没有图、只有外观时用这个。填写名称，以及年龄、脸型、发型、服装。可以再上传 1 到 3 张参考图（也可以从资源库选择）；有参考图时外观描述可以留空。1 张走系统设置里的「单张参考图工作流」，2 到 3 张走「多张参考图工作流」。参考图会先贴进 9:16 浅灰画布，保证四宫格是竖版。

可以点 ✨，用「系统设置」里的默认 LLM，套用提示词模板 **「角色库 · 角色外观」**（`character_sheet`）。优化只补脸型、头饰、下装鞋包和画质，不再写死排版；生成时后端会分别追加四宫格和横版四段的构图要求。

点 **「生成角色定妆照」** 后会依次执行：

1. 生成 9:16 四宫格，固定切成四张 9:16 单人图，立即保存。
2. 以四张图为参考，再跑一次图生图生成 16:9 横版四段。默认把四图拼成 16:9 参考底图，再用「多张参考图工作流」重绘；多图工作流不可用时退回单图编辑。
3. 如果 16:9 这一步失败，四张 9:16 视图不会丢；系统会保留它们，并改用四图合成一张 16:9 总览图，任务结果里会注明失败原因。

图像服务、四宫格工作流包、单张参考图工作流和多张参考图工作流都在 **「系统设置 → 默认角色生图」**，不在角色页选择。没有参考图时默认包是 `qwen_image_21`，四宫格目标尺寸 `1152×2048`；若所选包的宽高上限更小，会等比缩小并保持 9:16。

#### 上传设定图

手里已经有做好的设定图时用这个。先选排版：

- **16:9 横版四段**：从左到右必须是正面全身、侧面全身、背面全身、右侧面部特写。按人物之间的竖向空隙动态切分。
- **9:16 四宫格**：左上正面特写、右上正面全身、左下侧面全身、右下背面全身；四格等大并留浅灰间隔。按固定四等分切，每张仍然是 9:16。

上传框旁边也可以从资源库选择。外观描述可以不填；填写后，快速创作会把这段文字加到每个画面前面。点 **「保存并自动切分」** 立刻切开并建档，不调用图像服务。

不要把单张人物照、只有三段的三视图或排版与所选类型不符的图放进上传框；切分刀口可能落在人身上，或把邻格内容带进来。

切分规则：

- 16:9 横版：按每一列的明暗起伏找出三段人物之间的空隙，在空隙中点切开；空隙不够三条时退回大约 `23% / 22% / 23% / 32%`。右侧特写若还带着邻栏的灰边，会再沿顶部色块交界把切口往右挪。
- 9:16 四宫格：不分析空隙，直接按宽高中线四等分；因此生成或上传时必须保证人物不越过中线/横线。

卡片上的缩略图可以点开看大图，并用左右切换面部特写、正面全身、侧面全身、背面全身、16:9 定妆照和 9:16 四宫格原图。

图片文件在 `backend/data/characters/`。

### 分镜模板

设置 → 分镜模板。上传/删除分镜模板。文件名前缀：`static_` / `image_` / `video_`。画布尺寸须与画幅目录一致。内置不可删；用户同名覆盖内置。
