# 画布与导演台

画布节点、变量绑定、导演台对话与运行状态。

侧栏「工作台 → 画布」。一张画布是保存下来的流程图：输入、工作流包、语音、合成按连线依次执行。出图、出声、出视频仍交给已配置的服务提供方和工作流包。

## 打开与保存

从侧栏再次点「画布」，会打开上次编辑、且尚未点左上角「退出」的那张。「退出」回到列表，并取消这次自动打开。地址加上 `?mode=list` 也会直接进入列表。

列表里可以新建、复制、删除。删除会去掉这张图和节点上的执行记录。已经在节点上点过「保存到资源库」的成品仍留在资产里。

编辑器右上角：画布名称、保存（Ctrl+S；有未保存改动时按钮显示 `保存 *`）、分组（打开「设置 → 工作流包 → 画布分组」）、执行。点左上角「退出」时若有未保存修改，会先询问。

底部一排：撤销（Ctrl+Z）、重做（Ctrl+Shift+Z 或 Ctrl+Y）、添加节点、抓手、选择、整理。整理按依赖从左到右自动排开。

- 双击空白，或点底部 `+`，打开建点菜单。菜单分「功能」和「输入输出」。
- 从节点右侧圆点拖出连线。松在空白处会在落点建下游节点并自动接上。节点卡片上的 `+` 同样是向后建点。
- 抓手模式用左键拖动画布。选择模式用左键框选节点，中键或右键仍可拖动。滚轮缩放，范围约 0.25 到 1.8 倍。左下角小地图可平移和缩放。
- 连线不能成环，不能连进输入节点。视频合成只接视频，音频合成只接音频。Delete 或 Backspace 删除选中的节点或连线。
- 一张画布最多 200 个节点、400 条边。

## 分组：功能节点里的「所属」

功能节点先选「所属」，再选该组里的工作流包。还没有任何分组时，建点菜单里可以点「按能力建默认分组」：`t2i` / `i2i` / `upscale` 归入「图像」，`t2v` / `i2v` / `avatar` / `motion` 归入「视频」，`tts` / `asr` 归入「语音」，`analysis` 归入「画面分析」。

建点菜单的「功能」页列出图片、视频两类分组，下面固定是文字转语音和语音转文字。这两个语音节点走已配置的语音服务。只含语音工作流包、且包本身没有图片或视频输入的分组，不会出现在这个菜单里；先放入任意功能节点，再在右侧把「所属」改过去即可。

手动调整在「设置 → 工作流包」的「画布分组」页签：

1. **添加工作流包**：把每个包归到一个组。组名就是画布上的「所属」。
2. **分组管理**：新建、改名、删除。删除后，组里的包回到按能力命名的默认组：文生图、图生图、放大修复、文生视频、图生视频、数字人、动作迁移、画面分析。

从菜单点一个分组加入功能节点时，会载入该组第一个包，并按包的必填图片、视频、音频参数，在左侧补建输入节点再连上。上游已经能提供同类型媒体时不再补建。换包时，模型文件类参数回到新包的默认值，避免把上一套 UNET、文本编码器、VAE 带进另一系列。

## 节点

| 节点 | 作用 | 在右侧面板里设置 |
|------|------|------------------|
| **输入** | 提供图片、视频、音频、文本，或角色库里的一个人 | 媒体可上传，或从资产库挑选；图片输入还能直接从角色库选定妆照或某一视角，生成独立的图片变量。文本直接写。角色输入单独选人和入镜视角，不出现在图片输入的上传/资源库里。每个节点有输出变量名 |
| **功能** | 跑一个工作流包 | 所属、工作流包、包参数、提示词、输入槽。包声明了 Turbo / LoRA 时出现加速开关。数字人和动作迁移不手填时长：数字人跟随上游音频，动作迁移跟随参考视频；超过单段上限会分段，下一段用上一段尾帧。动作迁移可选「模型生成 / 参考视频原声」。这两类都可以从音乐库叠背景音乐。画面分析包产出文字，写入该节点变量 |
| **语音** | 文字转语音，或语音转文字 | 服务、音色或识别语言、输出格式。Liber Speech 还可选朗读语言。语音转文字可接音频或视频，转写正文写入该节点变量。服务留空时用第一个已启用且能力匹配的语音服务 |
| **合成** | 把多张图片拼成一张，或把多段视频 / 音频按顺序接成一条 | 顺序跟连线，可在面板里上下调整。图片合成可选横排、竖排、网格，设置列数、间隔和间隔颜色 |

图片输入可以「编辑图片」。导出后成为新版本，可随时点回旧版本（含当时的蒙版）：

- **标记**：涂抹笔迹烘进新图。
- **蒙版**：白区重绘、黑区保留，供局部重绘包使用。预检发现缺蒙版时，就在这里导出。
- **裁剪**：自由比例，或 1:1、4:3、3:2、16:9、9:16。只裁底图。
- **深度转换**：把当前底图交给已启用的 Liber Depth，生成一张深度图。本机深度插件未安装或未启用，并且服务提供方里也没有已启用的 Liber Depth 时，这个按钮是灰的。

换一张图会清空版本列表，新图作为「原始」。

## 导演台

画布左侧的「导演台」是一个对话式助手。它复用画布上的节点和资源，也能直接改这张画布。后端负责会话和模型调用；改画布的动作在浏览器里执行，所以每次改动都能用 Ctrl+Z 撤销。关掉页面后，这一轮对话停止，历史仍保存在会话里。

**面板**

- 默认停在左侧，「退出」按钮下方。拖标题栏可以移动，位置记在本机。
- 点右上角收起按钮，会变成底部左侧的一条窄栏。点输入框或展开按钮，回到展开状态。
- 顶部会话名单击打开会话列表：切换历史对话、新建对话、删除对话。双击会话名可以直接改名，回车保存，Esc 取消。每个画布分开存会话。

**模型**

输入框下方的「模型」按钮列出已启用服务商里勾选为对话的模型。默认是「跟随系统默认」，读取「系统设置」里的默认 LLM；点开可以换，当前会话会记住自己的选择。带「视觉」的能直接看图，带「工具」的会走原生工具调用；没有「工具」标记时退回文本协议，助手仍能改画布，只是格式由系统提示约束。

**附件与资源**

输入框下方的 `+` 打开附件菜单：

- 图片、视频、剧本/文本、音频分别上传。文件会以隐藏资产入档，不占资源库列表。
- 「从资源库选择」可以挑已有文件。
- 附件会随消息发给模型；图片缩到长边 1568px，视频均匀抽帧，音频只给一句提示，让助手先转写。
- 显式上传图片或视频、而当前模型没有视觉能力时，发送会被拦住，提示换模型或去掉媒体。

**引用画布节点**

在输入框键入 `/` 或 `@`，会列出画布上的节点：

- 绿色标记「仅配置」的节点还没产出，助手只能看到它的配置。
- 有产出的节点，助手会拿到配置摘要、变量名、资产 id 和文本产出。
- 选中后写入 `@变量名` 形式的引用，发送时换成结构化的节点摘要。
- 引用首先是为了让导演台**操作这个节点**：连线、断线、改属性、改输入、整理布局、执行或删除。模型有视觉能力时，才把节点的图片/视频一并附上；没有视觉能力时跳过媒体，只保留配置和 id，因此仍然可以断线或改属性，不会因为引用了一张图而被拦住。
- 如果用户想讨论画面内容本身，需要换一个带视觉能力的模型；显式上传的图片/视频仍会做视觉校验。

**节点右键菜单**

在画布节点上点右键，会在鼠标位置弹出菜单：

- 「添加到导演台」把该节点以 `@变量名` 的形式插入导演台输入框，和手动输入 `@` 引用效果相同；导演台收起时会自动展开。
- 「删除节点」等同于选中节点后按 Del，会连同相连的连线一起删除，进撤销栈。

**功能节点与执行**

- 导演台创建功能节点时先建空白节点，再读取「画布菜单设置」里的实际菜单项、可用工作流和默认工作流；没有合适菜单时才查找具体工作流包。不会直接写死工作流名。
- 套用菜单时如果已经有上游，会同时绑定输入槽并自动补上游连线，不再自动补建空输入节点；`bindings` 只决定槽位，媒体依赖必须存在直接连线。文本提示词直接写在功能节点上，不再自动生成空文本输入。视频节点引用组文本时用 `{{变量名}}`，不复制正文。
- 调整节点属性前可以先读取节点当前数据和参数规格：执行目标、输入槽、默认值、范围、当前 `values`。改 `values` 时整份写回，避免丢参数。
- 执行时只提交当前节点，上游默认按指纹复用，不会因为合成或生成一个节点而重跑整条链。
- 执行确认卡提供「执行当前节点」「强制执行含上游」「本会话自动允许」「取消」。只有选择「强制执行含上游」才会忽略上游缓存。

**技能**

内置五个技能：

| 技能 | 用途 |
|------|------|
| `director` | 按步骤做一条短片：主题、角色、剧本、分镜、创作路线、关键帧/参考图、视频。每步先问再确认 |
| `canvas-auto` | 自动搭画布：节点种类、变量名、绑定、提示词写法和执行约定 |
| `skill-creator` | 引导你把自己的流程写成技能 |
| `liberastra` | 不动画布，直接用服务端工具出图、出视频、配音和转写 |
| `project-info` | 只读项目资源：资产、角色、音色、音乐、菜单项、可用/默认工作流和当前节点参数 |

技能菜单可以切换当前技能、上传 `SKILL.md` 或 zip、管理启停和删除。上传包遵循 Agent Skills 标准：一个 `SKILL.md` 加可选的 `references/`、`assets/`、`scripts/` 和任意资源文件；不再限制文件后缀，也不禁止脚本。服务端只做路径穿越、压缩包解压大小和文件数量保护（单文件 8MB、整包 32MB、最多 1000 个文件），和内置技能同名仍会被拒绝。

内置技能已经拆成 `SKILL.md` + `references/` 或 `assets/`：主文件只保留核心流程，详细模板和参数按需读取，减少上下文占用。

**导演技能的两条视频路线**

- 生成分镜图片前先选创作路线：
  - **分镜视频**：每镜生成关键帧（数量用户选，可以多张，不合成），每镜一个视频节点，最后合并。重点是人物、服装、场景和风格一致。
  - **一段视频**：每镜生成一张分镜参考图，按单段上限内部切段；每段合成一张 1×N 参考图。不超过 15 秒用「参考图生视频」，超过 15 秒用「参考图生成视频（长）」。重点是运动、光线和音频连续。
- 节点类型由路线决定，不再让用户选择「图生视频 / 参考视频」。工作流和模型按画布菜单当前配置解析；要换目标时在节点属性面板的下拉里改，导演台不新建或修改工作流包。
- 分镜视频使用 `i2v_ref` 多参考图：当前关键帧、角色三视图、面部和场景可以同时传入；角色参考默认绑定，用户要求去掉时由画布技能断线并清掉 binding。`<Picture N>` 按实际已填槽位顺序编号。
- 一段视频不超过 15 秒时用一个参考图生视频节点；超过 15 秒时用 Extender 长视频，60 秒默认 4 段、每段不超过 15 秒，段间保持运动上下文，不再拆成多个独立视频再拼接。
- 菜单对应关系：`minimax_h3_i2v` 保留严格首帧/可选尾帧；`minimax_h3_i2v_ref` 同时服务「参考图生视频」和「分镜视频」；`minimax_h3_extender` 服务「参考图生成视频（长）」。
- 每步仍然先给方案、等确认；节点建完后可以自动整理画布，整理后检查分镜视频和合成节点的顺序。

**权限与确认**

- 加节点、改节点、连线、断线、整理布局：直接执行，进撤销栈。
- 高风险操作由安全路由拦截：删除节点、提交生成任务、写入技能文件、运行技能脚本。确认卡片列出操作和风险，提供「确认执行」「本会话自动允许」「取消」三个选择。
- 「本会话自动允许」只对当前会话记住该工具，后续同类操作不再弹卡；刷新或换会话后恢复默认。
- 执行类确认卡会写明是「普通执行（优先复用缓存）」还是「强制执行（忽略缓存）」，并列出节点 id。
- 技能脚本以 LiberAstra 后端进程权限运行，没有操作系统级沙箱；只能运行技能包 `scripts/` 目录内的脚本，输出截断、超时受限。首次运行和之后未自动允许时都需要确认。
- 导演技能的每一步：助手先给方案，得到你的确认再进下一步。
- 单轮最多 25 步，超过会停下来等你检查。

**图片合成节点**

建点菜单的「合成」里新增「图片合成」。把两张以上图片接进来，在右侧选横排、竖排或网格：

- 横排统一高度，竖排统一宽度，网格按最矮图片统一高度并紧排居中。
- 默认间隔 4px、白色；可以改间隔和颜色。网格会按所有输入中最矮的图片统一高度并紧排，避免不同宽高比在单元格里留下大片空白。
- 网格按行优先排列。导演台的参考图模式里，只生成首帧时是一行 N 张；首尾帧模式先连该组全部首帧、再连全部尾帧，得到 2 行 N 列，每列上下是一个分镜的首尾帧。
- 产物是 PNG，和视频、音频合成一样先作为画布中间结果，点「保存到资源库」后才进资产列表。

## 变量与提示词

每个节点有输出变量名，默认为类型加序号（如 `output_image_1`），可以改。与其他节点重名时输入框标红。

- 文本变量：在功能节点提示词或语音节点文案里写 `{{变量名}}`，或键入 `/` 从已连接节点插入。执行时换成文本输入、语音转文字或画面分析的正文。下游要接到产出文字的节点上，这样那段文字会先写进变量。引用了不存在的变量会失败。
- 媒体标签：`/` 插入 `<Picture 1>`、`<Video 1>`、`<Audio 1>` 这类标签，原样交给工作流。动作迁移包用 `<Picture 1>` 指人物图、`<Video 1>` 指参考视频。
- 输入槽：功能节点按包的每个媒体参数列一行，下拉绑定已连接节点的变量。`bindings` 只决定多个上游如何填槽，变量来源必须是直接连入该节点的上游；只绑定不连线会被预检拦下。未绑定时按媒体类型和连线顺序自动对应。蒙版只进入名字或说明里带「蒙版」的槽，多图编辑的下一张图仍按普通图片对应。

功能节点的提示词与各功能页相同，使用 **PromptField**：原始稿 / 优化稿、场景预设、✨、「使用优化后提示词」。勾选后，执行用优化稿再替换 `{{变量名}}`。✨ 使用「系统设置」里的默认 LLM。画布按当前工作流包的能力选用功能模板：文生图包用 `t2i`，图生图包用 `i2i`，放大包用 `upscale`，图生视频包用 `i2v`，文生视频包用 `t2v`。模板正文在「设置 → 提示词模板」里改。

## 执行与结果

点执行前会先检查：未选所属或工作流包、必填媒体没接上、局部重绘缺蒙版、提示词或文本为空、媒体文件没选。有问题的节点红框闪动，通知里写出第一条原因，本次不提交。

| 操作 | 结果 |
|------|------|
| 右上「执行选中」 | 先选中一个或多个节点。选中的节点重新跑；上游参数和素材没变时复用上次成功结果 |
| 右上「执行」 | 当前没有选中节点。确认后整张画布全部重跑，不复用 |
| 右侧「重新执行此节点」 | 只重跑当前节点；上游参数和素材没变时复用上次成功结果 |
| 右侧「强制执行含上游」 | 当前节点及其全部上游都重跑，忽略缓存 |
| 失败卡片上的「重试」 | 只重跑该节点；上游没变则复用 |

复用依据是指纹：工作流包、解析后的参数和提示词、上游资产。数字人和动作迁移还会带上声音来源、背景音乐和音量；用户以前填过的时长不参与执行。命中且上次成功时，预览角标显示「已复用」。

一条分支失败后，它的下游会因上游未成功而跳过，其他分支继续。刷新页面后，仍在排队或运行的节点会继续显示进度。这些任务同时出现在「任务中心」，可以取消或重试。画布右上角的「执行」在运行中会变成红色「停止」，点击并确认后会取消当前编排、停止后续节点，并向 ComfyUI 发送中断请求。功能页生成中再次点击主按钮，也会弹出中断确认；后端任务和 ComfyUI 任务会一起停止。

功能节点、语音节点和合成节点跑出来的图片、视频、音频先作为画布中间结果，资产库默认不列出。点预览右上角的保存图标，即「保存到资源库」，之后在资产里可见，节点上标成「已保存」。资产库打开「含画布中间结果」可以看到这些未发布文件，以及局部重绘蒙版。输入节点直接上传的文件，以及标记、裁剪导出的新图，会按普通资产生成。删除画布不影响已保存到资源库的成品。
