# 设置

服务提供方、工作流包、提示词模板与系统设置。

## 服务提供方

「设置 → 服务提供方」：名称、类型、地址、能力、密钥、启用。地址用 `http://`（本地误写成 `https://` 会协议错误）。ComfyUI 的 API Key 可留空。语音若设了 `LIBER_SPEECH_API_KEY`，Provider 里填同一 Key。

左侧搜索框只过滤服务商名称和说明，不是登录框。点开一份配置后填写 API 地址和密钥。Liber Depth 的类型名是「Liber Depth 深度图」，默认地址 `http://127.0.0.1:5556`，能力是深度图。本机插件启用时会自己建好这份配置；连局域网另一台深度服务时，在这里改地址，不要在插件页去启动远端进程。

各页「图像 / 视频 / 语音 / 识别服务」只列已启用且能力匹配的条目（如 `image`、`video`、`tts`、`asr`）。深度图页只列已启用的 Liber Depth。

## 工作流包

「设置 → 工作流包」可导入：

1. **LiberAstra 完整包**（含 `workflow` + `inputs` 等字段）
2. **ComfyUI API Format**（`Save (API Format)`）
3. **ComfyUI 画布 JSON**（含 `nodes` / `links`，可含子图）：导入文件或粘贴后点「转换画布 JSON」，会自动转成 API Format，并**启发式生成**能力、参数映射、输出节点、可选 `accel` / `fps` 草稿——**导入前请核对** node / field。

| 位置 | 说明 |
|------|------|
| `backend/workflows/` | 内置（随版本分发） |
| `backend/data/workflows/` | 用户包；同名覆盖内置 |

能力词表：`t2i` 文生图，`i2i` 图生图，`upscale` 图片增强，`v2v` 视频增强，`t2v` 文生视频（快速创作·生成视频），`i2v` 图生视频 / 素材动画，`avatar` 数字人，`motion` 动作迁移，`tts` 语音，`analysis` 看素材写文案。侧栏「工具」里的三种拼接是本机原生工具，不是工作流包，不出现在这里。

可选顶层 `accel`：前端出 Turbo 开关，提交带 `__accel`。包列表下拉先显示能力名和包的一句说明，越狱包会标「越狱版」；右侧灯泡显示 manifest 里的完整描述。

画布上的功能节点按「所属」选包。所属在本页「画布分组」页签里维护：把包归组、改名或删除。用法见 [画布 → 工作流分组](/guides/canvas#工作流分组)。

## 提示词模板

「设置 → 提示词模板」。✨ 优化时，发给默认 LLM 的系统提示词由两段拼成：**功能模板**说明这次在做什么，**场景预设**在后面再叠一层风格。内置条目随版本分发；用户文件只存覆盖层和自建条目。保存内容与内置一致时保持默认，不会显示「已自定义」；只有实际改过才显示。点「恢复默认」去掉覆盖，回到随版本分发的原文。保存后下一次优化立即使用新内容。

页签与按钮：

- **功能模板** / **场景预设**：左侧选条目，右侧改内容；没有改动时保存按钮不可用。
- **新建**：填写 ID。保存之后 ID 不可改。用和内置相同的 ID 保存，内容不同才会成为自定义覆盖。
- **导入**：粘贴 JSON。结构为 `{ "tasks": { "某id": { "name", "system", "capabilities" } } }` 或 `{ "scenes": { "某id": { "name", "append" } } }`。同名条目只有内容与内置不同才会成为自定义。
- **删除**：用户自建的「我的模板 / 我的预设」可以删除；内置条目不能删除，只能「恢复默认」。
- **导出**：下载当前合并结果 `prompts-catalog.json`。

也可以直接改 `data/prompts/tasks.yaml` 与 `scenes.yaml`。内置模板随应用包分发：源码在 `backend/prompts/`，安装包里在 `liberastra/prompts/`。`data/prompts/` 只放用户覆盖和自建条目；旧版本遗留的整份副本会与内置比较，与旧版默认完全相同的内容会自动清理，不会误标为自定义。容器部署不需要手工复制内置文件。升级后如果某个旧副本与新版内置内容不同，会保留并显示「已自定义」；点「恢复默认」即可采用新版内置内容。

### 功能模板

各页面和画布把固定的模板 ID 交给优化接口。下表是内置 ID。功能模板上的「适用功能」是逗号分隔的 capability，用来在本页标明它对应哪类能力；留空时本页不列出对应功能。

| ID | 名称 | 谁在用 |
|----|------|--------|
| `t2i` | 文生图 | 文生图页；画布上 capability 为 `t2i` 的功能节点 |
| `i2i` | 图生图 / 局部重绘 | 图生图与编辑 |
| `upscale` | 图片增强 | 工具 → 图片增强；画布上 `upscale` 包 |
| `i2v` | 图生视频 | 图生视频、自定义素材的动画提示词；画布上 `i2v` 包 |
| `t2v` | 文生视频 | 画布上 `t2v` 包 |
| `quick_visual` | 快速创作 · 画面提示词 | 快速创作的画面提示词 |
| `motion` | 动作迁移 | 动作迁移页 |
| `quick_topic` | 快速创作 · 主题扩写 | 快速创作的主题 |
| `assets_topic` | 自定义素材 · 主题扩写 | 自定义素材的主题 |
| `character_sheet` | 角色库 · 角色外观 | 角色库「按描述生成」 |

画布功能节点按所选包的 capability 取同名模板。没有同名模板时回落到 `t2i`。画面分析不走这条提示词框，分析角度写在包参数里。角色库固定用 `character_sheet`，不跟文生图页共用 `t2i`。`upscale` 模板只对声明了提示词槽的自定义放大包生效；内置 `upscale_basic` 和 SeedVR2 图片增强都没有提示词框。

### 场景预设

场景只追加风格，不更换上面的功能模板。PromptField 的场景下拉来自这里。内置九条：

| ID | 名称 | 倾向 |
|----|------|------|
| `auto` | 自动 / 通用 | 不强制海报、写真等固定场景，仍遵守功能模板 |
| `photo` | 摄影与写真 | 机身与胶片质感、焦段、抓拍 |
| `poster` | 海报与版式 | 主标题、信息栏、限定配色；图内文字逐字给出 |
| `illustration` | 插画与艺术 | 线条、上色、材质 |
| `product` | 商品与电商 | 主图、材质特写、卖点文案 |
| `character` | 角色与人设 | 立绘、服饰、表情 |
| `infographic` | 信息图与可视化 | 分区编号与短标签 |
| `architecture` | 建筑与空间 | 材质、光影、透视 |
| `cinematic_video` | 电影感分镜视频 | 景别、运镜、时序动作 |

选「自动」时仍会带上 `auto` 的叠加文本，其中写明不要强行套某一种画面类型。

### 各页上的 PromptField

文生图、图生图、图生视频、动作迁移、快速创作、自定义素材、角色库，以及带提示词槽的画布功能节点，提示词入口都是这一套：原始输入与优化稿切换、场景预设、✨、「使用优化后提示词」。原始稿、优化稿和开关写在本机浏览器，刷新后还在。

SeedVR2 图片/视频增强和普通放大包没有提示词槽，不显示这一栏。

✨ 提交任务 `prompt.optimize`：`POST /api/v1/prompts/optimize` 返回任务 id，前端轮询进度。服务端流式调用「系统设置」里的默认 LLM。刷新后凭任务 id 可以继续看到完成。优化时若带了工作流包名，会把包的能力、说明和模型家族一并交给 LLM。`?wait=true` 可同步等待。旧路径 `/api/v1/images/optimize-prompt` 仍同步返回。

接口：`GET /api/v1/prompts` 列出合并后的模板；`PUT /api/v1/prompts/tasks/{id}`、`PUT /api/v1/prompts/scenes/{id}` 保存覆盖；对应的 `DELETE` 即恢复默认；`POST /api/v1/prompts/import` 导入。

## 系统设置

账户改密。

**默认 LLM（脚本与提示词优化）**：选择服务商与模型，供快速创作、自定义素材、各功能页和画布功能节点上的 ✨ 统一使用。模板正文在上一节「提示词模板」里改。

**深度图生成**：选择默认深度服务商和模型，供深度图页和画布生成深度图使用。留空时用第一个启用的 Liber Depth 和 `dpt_swin2_large_384`。

**语音文字合成（Liber Speech）**：分别选择文字转语音模型、语音转文字模型和换音模型。文字转语音默认 `multilingual_v3`（Chatterbox-Multilingual V3）；语音转文字和换音默认跟随语音服务配置（`.env`），也可以在这里指定。文字转语音、语音转文字、换音、快速创作、自定义素材和数字人口播都会使用这里的默认值；功能页仍可按需改选。

**默认角色生图**：只给角色库「按描述生成」用。图像服务商默认取第一个启用的 `image` 服务；下面三个包分别对应主四宫格、1 张参考图、2～3 张参考图：

- 定妆照工作流包：只列 `t2i` 包，默认 `qwen_image_21`；用于生成 9:16 四宫格。
- 单张参考图工作流：只列 `i2i` 包，默认 `qwen_image_21_edit`；用于 1 张参考图的四宫格，以及 16:9 二次生成时多图工作流不可用的回退。
- 多张参考图工作流：只列 `i2i` 包，默认 `qwen_image_21_edit_multi`；用于 2～3 张参考图的四宫格，以及以四视图为参考的 16:9 定妆照。

换官方或越狱生图模型在这里改，不用回到角色页。

运行参数：ComfyUI 等待超时、接口同步等待、LLM 超时；「同主机服务串行」默认关（并行），开启后同机多服务同时只跑一个任务。保存后对下一个任务生效。

**通知**：任务完成、失败、运行进度推送和投递记录见 [通知](/guides/notifications)。
