# LiberAstra 使用文档

LiberAstra 是本机的编排界面。出图、出声、出视频都交给已配置的外部服务，本机不内置模型。

侧栏「使用文档」即本文。章节顺序与侧栏一致。

---

## 打开方式

生产环境只启动后端。先在 `frontend` 执行一次 `npm run build`，再在 `backend` 执行：

```powershell
uv run astra serve --reload
```

浏览器打开 `http://127.0.0.1:8000/`（接口与打包页面同端口）。

改界面时另开前端开发服务器 `http://127.0.0.1:5173/`；页面里的 `/api` 转到 8000。8000 上的页面要重新 `npm run build` 才会跟上源码。

一个账号可多浏览器同时登录；每张令牌约 12 小时，过期后重新登录。

## 先搞清三层：服务提供方 → 工作流包 → 模型文件

界面上常同时出现「服务 / Provider」「工作流包」「主模型 / 文本编码器 / VAE」等下拉，含义不同：

| 层 | 在哪选 | 决定什么 | 不决定什么 |
|----|--------|----------|------------|
| **服务提供方（Provider）** | 设置 → 服务提供方；各功能页的「图像/视频/语音服务」 | 请求发到**哪台机器**（地址、密钥、启用） | 用哪套模型、哪张计算图 |
| **工作流包** | 设置 → 工作流包；各功能页的「工作流 / 插图工作流 / 视频工作流」等 | **哪张 Comfy 计算图**、参数映射、能力（`t2i`/`t2v`/`i2v`…）、可选 Turbo | 服务地址 |
| **模型文件** | 包选中后，参数区按 manifest 的 `options_from` 展开 | 这台 Comfy 磁盘上**具体哪个权重文件** | 图的结构（由图决定） |

因此：

- 换一台 Comfy → 改 Provider。
- 换「官方 / 越狱 / 是否提示词增强 / 是否 Turbo」→ 主要靠**换包**，或同一包里换**成套模型文件**（见下文套餐表）。
- Comfy 网页上不必另建画布；LiberAstra 提交的是包内 API Format JSON。

能力对不上时，下拉会空或提示「无 xxx 工作流包」。例如快速创作「生成视频」只列 `capability: t2v` 的包，**选不到** `minimax_h3_i2v`（那是 `i2v`）。工作流包下拉右侧的灯泡会弹出当前包的用途说明。

## 图像

当前仓库主推 **Qwen-Image 2.1** 系列（与视频用的 MiniMax H3 **不是同一套模型**）。另有 **FLUX.3 Image Klein** 蒸馏三包，以及传统 SD checkpoint 包作备用。换下拉里的文件名时，按下面「成套」选，不要混系列、混量化、混 GGUF。

### 当前生图系列一览

| 系列 | 能力 | 工作流包 | 模型怎么选 |

| **官方** | `i2i` 整图 | `qwen_image_21_edit` | 三件套 + 1 张原图 |
| **越狱** | `i2i` 整图 | `qwen_image_21_edit_uncensored` | UC + LoRA 开关 |
| **官方** | `i2i` 多参考 | `qwen_image_21_edit_multi` | 三件套；2～4 张参考图 |
| **越狱** | `i2i` 多参考 | `qwen_image_21_edit_multi_uncensored` | UC + LoRA 开关 |
| **官方** | `i2i` 重绘 | `qwen_image_21_inpaint` | 三件套；原图 + 蒙版 |

### FLUX.3 Image Klein

三个包都是蒸馏版，图内已经接好 prompt upsampler（提示词扩展器）。ComfyUI 需要 **≥ 0.41**。采样固定 CFG 1、euler、simple，步数 16。24GB 用下面这一套，不要换成 bf16 或 NVFP4：

| 槽位 | 目录 | 文件 |
|------|------|------|
| UNET | `diffusion_models/` | `flux3-image-klein-int8-convrot.safetensors` |
| 文本编码器 | `text_encoders/` | `qwen3vl_4b_int8_convrot.safetensors` |
| 扩展器 | `text_encoders/` | `qwen3.5_9b_flux3_prompt_upsampler_w4a8.safetensors` |
| VAE | `vae/` | `flux2-vae.safetensors` |

CLIPLoader 的 type 保持 `flux3`。这套没有公开的图像底模越狱版，不要把 Qwen 的 UC UNET 或 LoRA 换进来。

#### 文生图：`flux3_klein`

侧栏「图像 → 文生图」。图像服务选 ComfyUI，工作流包选 `flux3_klein`。

1. 四个模型保持上表。扩展器会把短提示词扩成英文长描述，不要把它换成 Qwen-Image 的 8B 或视频用的 32B。
2. 提示词写画面内容即可，例如「窗边的陶瓷杯，柔和侧光」。
3. 宽高默认 1024，长边不超过 1536。页面上的步数会覆盖包内默认值，蒸馏版改回 **16**。CFG 固定为 1，页面上没有这项。
4. 24GB 显存张数保持 1。扩展器本身占显存。

#### 单图编辑：`flux3_klein_edit`

侧栏「图像 → 图生图与编辑」。只上传 **1 张**原图。

1. 提示词写改什么、保留什么，例如「把背景换成海滩，人脸和姿势保持不变」。
2. 没有宽高控件。输出尺寸跟原图，编码前参考图缩到约 1MP。
3. 步数 16，权重与文生图同一套。
4. 这个包没有画框。要涂抹局部重绘，改用 `qwen_image_21_inpaint`。

#### 多图编辑：`flux3_klein_edit_multi`

同一页，工作流包换成 `flux3_klein_edit_multi`。

1. 至少 2 张、最多 4 张。第 1 张是主图，决定输出尺寸（先缩到约 2MP，再按约 1MP 编码）。第 3、4 张可以不传；没传的槽会断开，不会拿占位图去跑。
2. 提示词按上传顺序写「第一张」「第二张」，例如「第一张里的人站在第二张的秋日森林观景台前」。这里不用 Qwen 多图包的「image 1」「image 2」。
3. 步数 16，CFG 固定为 1。

### 参考图调色

包名 `qwen_edit_2511_color_grade`，能力 `i2i`。侧栏「图像 → 图生图与编辑」。

它只换颜色：Qwen-Image-Edit-2511 加 Color Grade Transfer LoRA 生成约 1MP 的调色结果，再由 KJNodes 的 ColorMatch 把颜色贴回全尺寸原图，不重绘像素。

Comfy 环境需要：

- 节点包 [ComfyUI-KJNodes](https://github.com/kijai/ComfyUI-KJNodes)（提供 `ColorMatch`）
- 在 Comfy 的 Python 环境执行 `pip install color-matcher`

| 槽位 | 目录 | 文件 |
|------|------|------|
| UNET | `diffusion_models/` | `qwen_image_edit_2511_fp8mixed.safetensors` |
| 文本编码器 | `text_encoders/` | `qwen_2.5_vl_7b_fp8_scaled.safetensors` |
| VAE | `vae/` | `qwen_image_vae.safetensors` |
| 调色 LoRA | `loras/` | `QIE-2511-Color-Grade-Transfer-LoRA.safetensors` |

页面上：

1. 工作流包选 `qwen_edit_2511_color_grade`。
2. 第 1 张是要保留内容和分辨率的摄影原图，第 2 张是只借用颜色的参考图。顺序不要反。
3. **提示词留空**。留空会使用包内触发句 `Transfer ONLY the color grading from Image 2 onto Image 1`。写成普通修图指令（例如换背景、换衣服）会离开这条调色链路。
4. 步数 **20**，CFG **4**。这是不开 Lightning 时的官方模板。LoRA 强度默认 1。
5. 颜色迁移算法默认 `hm-mvgd-hm`，也可填 `mkl`、`hm`、`reinhard`、`mvgd`、`hm-mkl-hm`。调色强度 1 为完全套用参考色，0.7 更淡，0 等于原图。

这四件权重和 Qwen-Image 2.1 不是一套。下拉里如果出现 `qwen_image_2.1*`、`qwen3vl_8b*`、`qwen_image_2.1_vae*`，不要选。CLIPLoader 的 type 保持 `qwen_image`。24GB 用 fp8mixed；显存够可换同代 bf16，文本编码器仍用 `qwen_2.5_vl_7b`，VAE 仍用 `qwen_image_vae`。

### Qwen-Image 2.1：成套选模型（不要混搭）

选中包后，参数区有 UNET / TE / VAE 下拉。界面允许单独改名，但**必须按套餐整组选**。

#### 套餐表（推荐）

| 套餐 | 主模型 UNET（`diffusion_models/`） | 文本编码器 TE（`text_encoders/`） | VAE（`vae/`） | LoRA（`loras/`，仅越狱包） |
|------|-------------------------------------|-----------------------------------|---------------|---------------------------|
| **官方 INT8** | `qwen_image_2.1_int8_convrot.safetensors` | `qwen3vl_8b_int8_convrot.safetensors` | `qwen_image_2.1_vae_bf16.safetensors` | 无（官方包无 accel） |
| **越狱 UC INT8** | `qwen-image-2.1-UC-int8_convrot.safetensors` | **同上** `qwen3vl_8b_*` | **同上** | 推荐 `qwen-image-2.1-uncensored-lora.safetensors`（可关） |
| **官方更高精度** | `qwen_image_2.1_bf16.safetensors` 等 | 同族 `qwen3vl_8b_*` | 同上 VAE | 无 |

#### Uncensored LoRA 怎么用

1. 工作流包选 **`qwen_image_21_uncensored`**（或对应的 `*_edit*_uncensored` / `*_inpaint_uncensored`），不要选无 `_uncensored` 后缀的官方包。
2. 页面出现与视频 Turbo **同一套**控件：**Uncensored LoRA** 开/关 → 开时可选 LoRA 文件与强度（默认开、推荐 `qwen-image-2.1-uncensored-lora.safetensors`、强度 1.0）。
3. **关**：图中摘掉 `LoraLoaderModelOnly`，只用 UC UNET（仍可能比官方更松）。
4. **开**：LoRA 挂在 Cache 之后、采样之前；强度过高可能过拟合，可从 0.7～1.0 试。
5. 文件放在 Comfy 的 `models/loras/`；下拉按文件名含 `uncensored` 过滤。UC UNET 放在 `diffusion_models/`。
6. 快速创作「生成插图」选越狱包时，同样会出 LoRA 开关。

官方包里即使手动把 UNET 改成 UC，也**不会**自动加载该 LoRA。

#### 配对规则（必读）

1. **TE** 必须是 `qwen3vl_8b*`；**不要**选视频 H3 的 `qwen3vl_32b*` / `*_minimax_h3_*`。
2. **主模型** 必须是 `qwen_image_2.1*` / `qwen-image-2.1*`；**不要**选 `minimax_h3_*`、`wan_*`。
3. **VAE** 用 `qwen_image_2.1_vae*`；**不要**选视频 VAE。
4. **只选 `.safetensors`**，勿选 GGUF。
5. 越狱套餐：UNET 用 UC，TE/VAE 保持官方那两行；LoRA 用带 `uncensored` 的文件。
6. **CLIPLoader type** 保持 `qwen_image`。

下拉里认准 **`qwen_image` / `qwen-image` / `qwen3vl_8b` / `uncensored`**，避开 **`minimax` / `32b` / `h3` / `.gguf`**。

### 文生图

侧栏「图像 → 文生图」。选图像 Provider + `t2i` 工作流包。

- **`qwen_image_21`**：官方三件套。
- **`qwen_image_21_uncensored`**：UC + Uncensored LoRA 开关。
- **`flux3_klein`**：FLUX.3 Klein 蒸馏文生图。四件套、步数 16、扩展器不要换掉。详见上文「FLUX.3 Image Klein」。
- **`t2i_basic`**：`checkpoints/` 整包。

提示词可用右侧按钮经已配置的 LLM 改写。宽、高、步数、种子、张数按各包默认即可；`flux3_klein` 的步数改回 16。种子 `-1` 为随机，多张时从该种子逐张加 1。

### 图生图与编辑

侧栏「图像 → 图生图与编辑」。包能力一般为 `i2i`。官方 / 越狱成对出现；越狱包有 LoRA 开关。

- **整图编辑**：`qwen_image_21_edit` / `qwen_image_21_edit_uncensored`。
- **多参考编辑**：`qwen_image_21_edit_multi` / `…_uncensored`。至少 2 张、最多 4 张；第 1 张为主图（image 1）。提示词用「image 1」「image 2」指代。
- **局部重绘**：`qwen_image_21_inpaint` / `…_uncensored`。先原图后蒙版；白=重画，黑=保留。`grow` 扩白区。
- **FLUX.3 单图编辑**：`flux3_klein_edit`。1 张原图，提示词写修改指令，步数 16。详见上文。
- **FLUX.3 多图编辑**：`flux3_klein_edit_multi`。2～4 张，提示词用「第一张」「第二张」，步数 16。详见上文。
- **跟参考图调色**：`qwen_edit_2511_color_grade`。第 1 张原图、第 2 张调色参考，提示词留空，步数 20、CFG 4。模型与节点要求见上文「参考图调色」。

上传区支持多选与单独删除；原图/蒙版有角标区分。

### 修复与放大

侧栏「图像 → 修复与放大」，包 `upscale_basic`。走 Upscale 模型（约 4×），不是生图。权重放在 ComfyUI `upscale_models/`。提示词可留空。

## 视频

侧栏顺序：**快速创作** → **自定义素材** → **数字人口播** → **图生视频** → **动作迁移** → **角色库** → **模板管理**。

### 各页要选什么包

| 侧栏功能 | 页面相关下拉 | 包能力 | 仓库现状（内置） |
|----------|--------------|--------|------------------|
| 快速创作 · 生成插图 | 插图服务 + 插图工作流 | `t2i` | `qwen_image_21` / `qwen_image_21_uncensored`、`flux3_klein`、`t2i_basic` |
| 快速创作 · 生成视频 | 视频服务 + 视频工作流 | `t2v`（仅提示词，无首帧） | `minimax_h3_t2v`（官方）、`minimax_h3_t2v_uncensored`（越狱无增强）、`minimax_h3_t2v_enhancer`（越狱+增强） |
| 自定义素材 · 素材动画 | 动画服务 + 动画工作流 | `i2v` | `minimax_h3_i2v` / `minimax_h3_i2v_uncensored` / `minimax_h3_i2v_enhancer` |
| 自定义素材 · 看素材写文案 | 分析服务 + 分析工作流 | `analysis` | 有 Qwen-VL 分析包 |
| 数字人口播 | 视频服务 + 包；另选配音 | `avatar` 等 | `minimax_h3_avatar` / `minimax_h3_avatar_uncensored` |
| 图生视频 | 视频服务 + 工作流包 | `i2v` | 有上述三个 H3 包 |
| 动作迁移 | 视频服务 + 工作流包 | `motion` 等 | `minimax_h3_motion` / `minimax_h3_motion_uncensored` |
| 角色库 · 按描述生成 | 不在本页选。用「系统设置 → 默认角色生图」 | `t2i` | 默认 `qwen_image_21`；也可换 `qwen_image_21_uncensored`、`flux3_klein` |

### 页面上怎么选（通用）

1. **视频 / 插图 / 动画服务**：已启用且能力匹配的 Provider。选 ComfyUI 后，模型列表从该机 `/models/...` 拉取。
2. **工作流包**：按上表能力过滤。选中后：
   - 包声明但磁盘缺失的模型 → 黄字警告（不拦截提交）。
   - 展开参数：主模型、文本编码器、VAE、LoRA 等。
   - 包有 `accel` → **Turbo 加速**开关 + 加速模型 + 强度；开则注入 LoRA，并把步数、采样器切到预设（H3 为 8 步、`euler`），关则从图中摘掉加速节点。
3. **宽高 / 时长**：图生视频用宽高比，按包 `multiple` 吸附（H3 常为 32）。有 `fps` 的包按「秒」设时长，提交换算帧数并按 `align_base`/`align_offset` 吸附（H3 为 17k+5）。数字人口播不显示时长，画面跟着配音走。
4. H3 / 长任务：建议「设置 → 运行参数」里 **ComfyUI 等待超时** ≥ 3600 秒。

### MiniMax H3：版本 = 成套文件（不要混搭）

Comfy 上同一「功能」往往对应**多份文件**。界面下拉可以单独换文件名，但**官方 / 越狱 / 量化规格要成套选**，否则容易加载失败或效果异常。

#### 共用（官方与越狱都要用）

| 角色 | 目录 | 当前推荐文件（远程常见） |
|------|------|--------------------------|
| 主模型 FL2VA（图生/文生视频画面+音） | `diffusion_models/` | `minimax_h3_fl2va_pruned_int8_convrot.safetensors` |
| 视频 VAE | `vae/` | `minimax_h3_video_vae_fp16.safetensors` |
| 音频 VAE | `vae/` | `minimax_h3_audio_vae_fp32.safetensors` |
| Turbo LoRA（可选） | `loras/` | `minimax_h3_turbo_v4_step600_ema.safetensors`。节点是 `MiniMaxH3TurboLoRA`（需安装 [Larryvrh/ComfyUI-MiniMax-H3-Turbo](https://github.com/Larryvrh/ComfyUI-MiniMax-H3-Turbo)）；调度器保持 `simple`。下拉只列出文件名含 `_ema` 的权重 |

主模型不要和 Ref2VA（`minimax_h3_ref2va_*`）混用。其它量化（未剪枝 INT8、FP8、W6A8 等）体积不同，换主模型时整条链路仍用同一套 VAE。

#### 文本侧：官方套餐 vs 越狱套餐

| 套餐 | 文本编码器（TE，`text_encoders/`） | 生成尾（tail，仅提示词增强需要） | 对应内置包 |
|------|-------------------------------------|----------------------------------|------------|
| **官方** | `qwen3vl_32b_minimax_h3_nvfp4_awq.safetensors` | 一般不需要；若官方增强需同族 `…instruct_generation_tail…` | `minimax_h3_i2v` / `minimax_h3_t2v` |
| **越狱 NVFP4（无增强）** | `qwen3vl_32b_heretic_minimax_h3_nvfp4.safetensors` | 不需要 | `minimax_h3_t2v_uncensored` / `minimax_h3_i2v_uncensored` |
| **越狱 INT8 + 增强** | `qwen3vl_32b_h3_ultra_uncensored_heretic_int8_convrot.safetensors` | `qwen3vl_32b_h3_generation_tail_50_63_int8_convrot.safetensors` | `minimax_h3_i2v_enhancer` / `minimax_h3_t2v_enhancer` |

配对规则：

- **TE 与 tail 必须同族**（官方配 instruct tail，越狱配 heretic 配套 tail）。
- `CLIPLoader` 的 type 均为 `minimax`；换文件不等于换节点类型。
- 在 `minimax_h3_i2v` 里只把 TE 下拉换成越狱文件 = **不增强提示词的越狱出片**（仍可不装 Guide）。要「看图改写提示词」必须用 enhancer 包，并装 [Guide 节点包](https://github.com/ethanfel/ComfyUI-MiniMax-H3-Guide)。

#### 量化怎么理解

同一角色常有多种量化文件（如 TE 的 nvfp4 / int8_convrot / bf16）。**选一个规格用到底**，不要主模型用 pruned-int8、TE 却随便混一个未验证组合。3090 上官方 nvfp4 可跑但非最快；越狱 TE（约 25G）更吃内存，远程 62G 机器上建议单独观察是否 OOM。

更细的文件清单与 SHA 见 `docs/MiniMax-H3加速与越狱工作流开发计划.md`。

### 快速创作

一句话或固定文案 → 口播 + 分镜画面 → 拼接。页面分块：

1. **视频脚本**：AI 创作 / 固定文案 / 批量；可「生成分镜后暂停」。
2. **画面提示词优化**（插图/视频模板才出现）：默认开，由用户开关决定。脚本服务 LLM 把口播改写成画面描述。静态模板不走这步。Guide 增强只由工作流包决定（`*_enhancer` 包内有 Guide，`*_uncensored` 等没有），与该开关无关。
3. **分镜模板**（先选模式再选模板）：
   - **静态样式**：本地 HTML，不跑 AI 生图/生视频；也不调用画面提示词 LLM。
   - **生成插图**：逐镜 `t2i`。
   - **生成视频**：逐镜 `t2v`。界面选「视频服务」「视频工作流」；包有 `accel` 时可开 Turbo。
4. **文字与字幕**、**配音**、**背景音乐**（音乐库，音量建议 0.1–0.3）。生成视频模板可以在「自定义配音」和「模型原声」之间切换：自定义配音按文案合成并替换音轨；模型原声保留文生视频自己生成的声音。静态模板和插图模板只有自定义配音。配音选本地 TTS 或 API TTS 时，音色下面可以试听，见 [文字转语音](#文字转语音)。
5. **登场角色**（可选）：从角色库选一个。外观描述会加在每个画面提示词前面；定妆照里的「16:9 横版、四个视角」等排版句会先去掉。这里只带文字，不把定妆照图片送进分镜。

脚本服务 LLM 何时用：

| 模式 | 写口播 | 写画面提示词（可关） |
|------|--------|----------------------|
| AI 创作 / 批量 | 是 | 插图/视频模板且开关开 |
| 固定文案 | 否（原文切分） | 插图/视频模板且开关开 |

#### 文生视频（`t2v`）选哪个包？

快速创作「生成视频」只列 `capability: t2v` 的包（看不到 `i2v` 包是正常的）。

| 包名 | 文本侧 | 说明 |
|------|--------|------|
| `minimax_h3_t2v` | 官方 TE | 纯提示词出片；可 Turbo |
| `minimax_h3_t2v_uncensored` | 越狱 **NVFP4** TE | **越狱、无增强**（对应本地画布【文生视频】）；默认 LightX2V 8-step Turbo；可 Turbo |
| `minimax_h3_t2v_enhancer` | 越狱 INT8 TE + tail | **越狱 + 提示词增强**；需 Guide；结果可看增强文本；可 Turbo |

三者都**不接首帧**（`MiniMaxH3ImageToVideo` 的 `first_frame` 可选）。图生视频请用 `minimax_h3_i2v` / `minimax_h3_i2v_uncensored` / `minimax_h3_i2v_enhancer`。

### 自定义素材

已有图片或视频，配口播和字幕，按上传顺序拼成一条短片。画面默认保持原样。

页面从上到下是：素材 → 文案与标题 → 素材动画 → 配音 → 画幅与背景音乐。打开素材动画或上传了视频时，配音可以改成「模型原声」，保留动画或视频自带的音轨。点「开始合成」后的顺序是：文案已经定好 → 有标题则先做 2 秒标题卡 → 自定义配音时逐段合成并写字幕，模型原声时按片段自身时长写字幕 → 图片按开关保持静止或做动画 → 拼成一条 → 有背景音乐再混入。

#### 素材

顺序就是分镜顺序，可多次添加。每一段视频会循环或截断到这句配音的时长。

#### 文案与标题

标题选填。填写后，片头是一张 2 秒标题卡。

文案三选一，互不影响：

| 选项 | 怎么得到口播 | 看不看画面 |
|------|----------------|------------|
| 自备文案（按行对应素材） | 自己写。每行一句，对应素材顺序；行数不够会循环使用 | 不看 |
| 主题生成文案 | 只填主题和目标时长。按文件名、视频时长写口播。需要「系统设置」里的默认 LLM | 不看 |
| 看素材写文案 | 上传素材后点「生成文案」。视觉模型先看每张图、每段视频，再写成口播。生成后可以改，出片用的就是这段文字 | 只在点「生成文案」时看一次 |

看素材写文案还要选：

- **分析服务**：执行分析的 ComfyUI。
- **图片分析工作流**：有图片时必选。内置 `analysis_image_qwenvl`，需要 ComfyUI-AILab 和 Qwen-VL（默认 Qwen3-VL-8B-Instruct）。
- **视频分析工作流**：有视频时必选。内置 `analysis_video_qwenvl`，还需要 Video Helper Suite 抽帧。
- **补充要求**、**目标时长**：选填。用来指定语气、卖点和句子长短。留空就只按画面写。

没上传素材时「生成文案」不可用。这段口播为空时不能开始合成。

#### 素材动画

开关默认关闭。打开后，只在「开始合成」里、这一段配音完成之后生效：每张静图单独走一次 `i2v`，生成一小段运动画面，再循环或截断到这句配音的时长，然后配上字幕。

上传的视频和标题卡保持原样。当前素材里没有图片时，开关不可用。

动画提示词留空时，默认轻微、自然的镜头前推。填写后使用你写的运动描述。工作流选 `i2v` 包：`minimax_h3_i2v`、`minimax_h3_i2v_uncensored`、`minimax_h3_i2v_enhancer`。包有 `accel` 时可开 Turbo。每张图一次图生视频，张数越多越慢。

#### 配音、画幅与背景音乐

配音按素材逐段合成，字幕时长跟这句配音走。配音服务是 ComfyUI 时要另选语音工作流，口播文本自动注入。本地 TTS 或 API TTS 可以在音色下面试听，见 [文字转语音](#文字转语音)。画幅为 9:16、1:1 或 16:9。背景音乐从音乐库选择，在全片拼完之后混入。

### 数字人口播

人物图 + 口播文案 → TTS 语音 → `avatar` 工作流包。内置两套基于 MiniMax H3 音画联合模型的口播工作流（无需额外安装嘴型插件或音频编码器）：

| 包名 | 默认文本侧 | 原理与特点 |
|------|------------|------------|
| `minimax_h3_avatar` | 官方 TE | `MiniMaxH3ImageToVideo` 锁定首帧人物，`MiniMaxH3AddGuide` 在第 0 帧锚定 TTS 语音潜变量驱动口型与表情，成片直接合成清晰 TTS 原声；可开 Turbo |
| `minimax_h3_avatar_uncensored` | 越狱 **NVFP4** TE | 同上，默认使用越狱文本编码器；可开 Turbo |

另选配音服务与音色。画面时长由这段配音决定，页面上不再手填秒数：帧数按 `17k+5` 向上取整后再裁回配音长度，只多留约一帧。估算超过约 12 秒、或合成后仍超过单段上限（362 帧，约 15 秒）时，按句子切开，下一段用上一段尾帧当首帧，最后合成一条视频。后面各段不再回到角色定妆照，段数很多时人物仍可能慢慢跑偏。成片之后可以再从音乐库叠一条背景音乐。本地 TTS 或 API TTS 可以在音色下面试听，见 [文字转语音](#文字转语音)。

人物图可以上传，也可以从角色库选择。选了角色时，**只有第一段**用定妆照右侧的**面部半身特写**当首帧，不用全身图，也不用整张设定图。上传的图片优先于角色库。角色若绑定了音色，配音没另选时会带上。

### 图生视频

首帧 + 提示词 → `i2v`。成片保留模型自己生成的音轨，也可以再从音乐库叠一条背景音乐。

| 包名 | 默认文本侧 | 特点 |
|------|------------|------|
| `minimax_h3_i2v` | 官方 TE | 提示词原样进生成；可 Turbo |
| `minimax_h3_i2v_uncensored` | 越狱 **NVFP4** TE | **越狱、无增强**；默认 LightX2V 8-step；可 Turbo |
| `minimax_h3_i2v_enhancer` | 越狱 INT8 TE + tail | 先 Guide 增强再出片；结果区可看增强文本；可 Turbo；需 Guide |

enhancer 更慢、更吃内存；适合提示词很短或希望先改写成 H3 规范长提示词的场景。

选了角色库里的角色后，再选这一镜的首帧：面部半身特写、正面全身、侧面全身或背面全身。近景用特写，全身动作用对应全身图。上传的图片优先于角色库。

### 动作迁移

参考视频 + 目标图 + 提示词 → `motion` 工作流包。画面时长跟随参考视频，页面上不再手填秒数。参考视频按模型单段上限（H3 为 362 帧，约 15.08 秒，且满足 `17k+5`）切开；下一段把上一段成片尾帧当作 `<Picture 1>`，侧面和背面参考仍然保留，最后拼成一条。声音可以留模型生成的音轨，也可以换成参考视频的整条原声。两种都可以再从音乐库叠背景音乐。内置两套基于 MiniMax H3 多模态参考（`MiniMaxH3ReferenceToVideo`）的动作迁移工作流。选了角色库里的角色时，把**正面全身、侧面全身、背面全身**分别送进 `<Picture 1>`、`<Picture 2>`、`<Picture 3>`。右侧面部特写不参与动作迁移，避免下半身服装丢失。上传的图片优先于角色库。

| 包名 | 默认文本侧 | 原理与特点 |
|------|------------|------------|
| `minimax_h3_motion` | 官方 TE | `VHS_LoadVideo` 按 24fps 抽帧作为 `<Video 1>` 动作参考，目标图作为 `<Picture 1>` 身份参考，无需骨骼预处理即可迁移肢体动作与运镜；可开 Turbo |
| `minimax_h3_motion_uncensored` | 越狱 **NVFP4** TE | 同上，默认使用越狱文本编码器；可开 Turbo |

提示词中可用 `<Picture 1>` 指代目标图、`<Video 1>` 指代参考视频；若未写标签或留空，流水线会自动补齐标准动作迁移指令。也可自行导入 `WanAnimate2ToVideo` 或 `WanSCAILToVideo` 工作流包。

### 角色库

侧栏「角色库」保存一个角色的名称、外观描述和一张 **16:9 四段式定妆照**。定妆照从左到右固定四栏：

| 从左到右 | 内容 | 存成 | 谁在用 |
|----------|------|------|--------|
| 第 1 栏 | 完整全身正面 | 正面全身 | 图生视频、动作迁移 `<Picture 1>` |
| 第 2 栏 | 完整全身侧面 | 侧面全身 | 图生视频、动作迁移 `<Picture 2>` |
| 第 3 栏 | 完整全身背面 | 背面全身 | 图生视频、动作迁移 `<Picture 3>` |
| 第 4 栏 | 右侧超大面部半身特写 | 面部特写 | 数字人口播、图生视频近景 |

整张设定图只用于预览和切分，不会被当成视频画面。页面上先选一种添加方式，另一种的按钮不会同时出现。

#### 按描述生成

手里没有图、只有外观时用这个。填写名称，以及年龄、脸型、发型、服装。可以再上传 1 到 3 张参考图；有参考图时外观描述可以留空。1 张走系统设置里的图生图包，2 到 3 张走多图编辑包。第一张会先贴进 16:9 浅灰画布，保证定妆照是横版。可以点 ✨，用「系统设置」里的默认 LLM，套用提示词模板 **「角色库 · 四段式定妆照」**（`character_sheet`）。优化会补上匹配的脸型、头饰、下装鞋包，并写上固定的四段式构图和画质要求。

点 **「生成角色定妆照」**。这一步自己建档并排队生图，不用再点保存。图像服务、文生图包和图生图包在 **「系统设置 → 默认角色生图」**，不在角色页选择。没有参考图时默认包是 `qwen_image_21`，画幅 16:9（`1536×864`；若所选包的宽高上限更小，会自动缩小）。没点优化时，后端也会把四段式构图补在外观描述后面。点过优化、提示词里已经有「16:9」或「完整全身正面」时，不再重复追加。

#### 上传设定图

手里已经有做好的横版四段图时用这个。从左到右必须是正面全身、侧面全身、背面全身、右侧面部特写。背景用浅色或纯色，四个人物之间留出竖向空隙。外观描述可以不填；填写后，快速创作会把这段文字加到每个画面前面。

点 **「保存并自动切分」**。立刻切开并建档，不调用图像服务。

不要把下面两种图放进这个上传框：

- 只有正面、侧面、背面的三段式三视图。第四栏会被当成面部特写，背面可能被切进侧面。
- 单张人物正面照。没有竖缝时会按比例切成四条，刀口可能落在人身上。

切分规则：按每一列的明暗起伏找出三段人物之间的空隙，在空隙中点切开。空隙不够三条时，才退回大约 `23% / 22% / 23% / 32%`。右侧特写若还带着邻栏的灰边，会再沿顶部色块交界把切口往右挪。卡片上的缩略图可以点开看大图，并用左右切换面部特写、正面全身、侧面全身、背面全身和定妆照原图。

图片文件在 `backend/data/characters/`。

### 模板管理

分镜模板上传/删除。文件名前缀：`static_` / `image_` / `video_`。画布尺寸须与画幅目录一致。内置不可删；用户同名覆盖内置。

### ComfyUI 模型目录（速查）

| 用途 | 目录（相对 `models/`） | 生图 Qwen-Image 常见文件前缀 |
|------|------------------------|------------------------------|
| 图像/视频主模型（UNET） | `diffusion_models/` | `qwen_image_2.1*` / `qwen-image-2.1*`（**勿**混 `minimax_h3_*`） |
| 文本编码器 / 生成尾 | `text_encoders/` | 图像用 `qwen3vl_8b*`；视频 H3 用 `qwen3vl_32b*`（**勿混用**） |
| VAE | `vae/` | 图像用 `qwen_image_2.1_vae*`；视频用 `minimax_h3_*_vae*` |
| Turbo / UC 等 LoRA | `loras/` | 视频 Turbo；图像越狱包用 `qwen-image-2.1-uncensored-lora*` |
| 传统 SD checkpoint | `checkpoints/` | 仅 `t2i_basic` |
| 放大 | `upscale_models/` | `upscale_basic` |

## 语音

语音是独立 Provider，不在 LiberAstra 进程内。

### 文字转语音

按服务类型出不同控件：

| 配音服务 | 音色怎么选 | 试听 |
|----------|------------|------|
| 本地 TTS（`edge_tts`） | 服务音色列表，例如 `zh-CN-XiaoxiaoNeural` | 有 |
| API TTS（OpenAI 兼容） | 服务音色列表，例如 `alloy` | 有 |
| Liber Speech | 音色库，或「使用默认声音…」再选语言 | 无。克隆音色直接播放音色库里的参考音频 |
| ComfyUI 语音工作流 | 工作流包参数 | 无 |

试听出现在文字转语音、数字人口播、快速创作和自定义素材。输入框默认是「你好,这是一段试听语音! 」，也可以改成别的短句（最多 200 字）。点喇叭用当前音色当场合成并播放，不进入任务队列，也不保存成资产。

Liber Speech 选音色库条目时，会把这条参考音频发给 Speech 做克隆。选「使用默认声音…」时不传参考音频，模型用自带声音，语言下拉只决定用哪种语言读（默认中文 `zh`）。朗读语言只影响发音，不翻译正文。

### 语音转文字

上传音/视频；语言可自动或 `zh`/`en` 等。输出按 txt、json、srt、vtt 取第一种可用。

### 音色库

本地克隆：上传参考音频 + 参考文字，`voice_id` 留空。仅云端复刻返回编号时才填 `voice_id`。

### 音乐库

BGM 上传/试听/删除；同名自动加序号。快速创作与自定义素材从这里选。

## 设置

### 服务提供方

「设置 → 服务提供方」：名称、类型、地址、能力、密钥、启用。地址用 `http://`（本地误写成 `https://` 会协议错误）。ComfyUI 的 API Key 可留空。语音若设了 `LIBER_SPEECH_API_KEY`，Provider 里填同一 Key。

各页「图像 / 视频 / 语音 / 识别服务」只列已启用且能力匹配的条目（如 `image`、`video`、`tts`、`asr`）。

### 工作流包

「设置 → 工作流包」可导入：

1. **LiberAstra 完整包**（含 `workflow` + `inputs` 等字段）
2. **ComfyUI API Format**（`Save (API Format)`）
3. **ComfyUI 画布 JSON**（含 `nodes` / `links`，可含子图）：导入文件或粘贴后点「转换画布 JSON」，会自动转成 API Format，并**启发式生成**能力、参数映射、输出节点、可选 `accel` / `fps` 草稿——**导入前请核对** node / field。

| 位置 | 说明 |
|------|------|
| `backend/workflows/` | 内置（随版本分发） |
| `backend/data/workflows/` | 用户包；同名覆盖内置 |

能力词表：`t2i` 文生图，`i2i` 图生图，`upscale` 放大，`t2v` 文生视频（快速创作·生成视频），`i2v` 图生视频 / 素材动画，`avatar` 数字人，`motion` 动作迁移，`tts` 语音，`analysis` 看素材写文案。

可选顶层 `accel`：前端出 Turbo 开关，提交带 `__accel`。

### 系统设置

账户改密。

**默认 LLM（脚本与提示词优化）**：选择服务商与模型，供快速创作、自定义素材、各页提示词 ✨ 统一使用。

**默认角色生图**：只给角色库「按描述生成」用。图像服务商默认取第一个启用的 `image` 服务；定妆照工作流包只列出 `t2i` 包，默认 `qwen_image_21`。换官方或越狱生图模型在这里改，不用回到角色页。

运行参数：ComfyUI 等待超时、接口同步等待、LLM 超时；「同主机服务串行」默认关（并行），开启后同机多服务同时只跑一个任务。保存后对下一个任务生效。

### 提示词优化与模板库

文生图 / 图生图 / 修复放大 / 图生视频 / 动作迁移 / 快速创作 / 自定义素材 / 角色库等页面的提示词入口使用统一 **PromptField**：原始输入与优化后提示词双栏切换、场景预设、✨ 覆盖生成、「使用优化后提示词」开关。角色库使用任务模板 `character_sheet`（角色库 · 四段式定妆照）。原始稿与优化稿（含开关）均写入浏览器 localStorage，刷新后仍在。

✨ 提交后端 Job（`prompt.optimize`）：`POST /api/v1/prompts/optimize` 返回任务 id，前端轮询进度；服务端流式调用 LLM 并增量写入 `outputs`，刷新后仍可凭 jobId 继续查看直至完成。原始/优化稿同时写入浏览器 localStorage。

- API：`GET /api/v1/prompts`、`POST /api/v1/prompts/optimize`（`?wait=true` 可同步等待；旧路径 `/api/v1/images/optimize-prompt` 仍同步返回）。
- 模板：内置 `backend/prompts/`，首次启动同步到 `data/prompts/`（`tasks.yaml` / `scenes.yaml`），可手工编辑或 `PUT` / `POST /import` 覆盖。
- 详细设计见 [全局提示词优化与模板库开发计划](./全局提示词优化与模板库开发计划.md)。

## 文件放在哪

后端从 `backend` 启动时：

| 内容 | 路径 |
|------|------|
| 数据库 | `backend/data/liberastra.db` |
| 生成物 | `backend/data/outputs/` |
| 上传 | `backend/data/uploads/` |
| 用户工作流包 | `backend/data/workflows/` |
| 用户模板 | `backend/data/templates/` |
| 提示词模板 | `backend/data/prompts/` |
| 音乐库 | `backend/data/bgm/` |
| 角色图片 | `backend/data/characters/` |

`backend/data` 不要放进网盘/同步目录，否则可能锁库报 `disk I/O error`。
