# 分镜与视频提示词模板

写提示词时按这个顺序组织，避免遗漏人物一致性和镜头运动约束。

## 分镜提示词

```text
[主题与场景]
{一句话主题}，{时间/天气/环境}，{地点}。

[人物一致性]
{角色名}，{年龄段}，{发型}，{服装}，{体型}，{气质}。
如使用角色节点，写：保持 <Picture 1> 中人物的五官、发型和服装一致。
如使用文本变量，写：角色设定参考 {{input_text_character}}。

[镜头]
{景别：远景/全景/中景/近景/特写}，{机位：平视/俯拍/仰拍/过肩}，
{构图：居中/三分/对称/前景遮挡}，{光影：自然光/侧逆光/霓虹/柔和棚拍}，
{镜头语言：缓慢推近/手持跟随/固定机位/环绕}。

[动作与物理]
{人物正在做什么}，{动作方向}，{衣物/头发/道具的物理反应}，
{画面中必须保持稳定的元素}。

[风格]
{写实电影感/动画/胶片颗粒/赛博朋克/水墨}，{色调}，{画质关键词}。
```

## 分镜视频：关键帧提示词

只用于“分镜视频”路线。每镜生成 1～N 张关键帧，**不拼接**。

- 第 1 张：开场画面，动作起点。
- 最后一张：如果用户需要结束状态，写收束画面和动作终点。
- 中间关键帧：只写该时刻的构图、人物位置和动作阶段，不写“开场/收尾”。

单张关键帧模板：

```text
{分镜提示词}

[关键帧]
{该时刻的画面}：{人物位置}，{动作阶段}，{构图}，{必须保持一致的元素}。
```

首尾两张时，尾帧额外写：

```text
[衔接] 与开场关键帧保持同一人物、服装、场景和光线，只改变动作阶段与机位。
```

## 分镜视频：视频提示词

每一镜一个视频节点，使用 `i2v_ref` 的多参考图。提示词开头必须写 `subject_definitions`，按实际已填槽位顺序编号：

```text
subject_definitions:
<Picture 1> = 本镜关键帧 1，主参考；
<Picture 2> = 本镜关键帧 2（如果有）；
<Picture 3> = 角色正面；
<Picture 4> = 角色侧面；
<Picture 5> = 角色背面；
<Picture 6> = 角色面部；
<Picture 7> = 场景参考。
槽位必须按这个顺序连续填，中间不要留空；只有实际存在的图才写进 subject_definitions。

[镜头] {景别}，{机位}，{构图}，{镜头运动}。
[动作] {主体动作}，{动作方向}，{衣物/头发/道具的物理反应}。
[一致性] 保持 <Picture 1> 的构图与动作起点，保持 <Picture 2>～<Picture 5> 的人物外观，
保持 <Picture 6> 的场景、光线和色调。
[声音] {环境音/音效/对白}。
[不要] 不要额外人物、文字、水印、突变镜头。
```

如果实际只填了部分参考图，按实际顺序重新编号，不要沿用模板里的固定编号。

## 一段视频：分镜参考图提示词

每镜只生成一张参考图，用于拼接 1×N 分镜参考图。它不是严格首帧/尾帧。

```text
{分镜提示词}

[参考图]
{该分镜的代表画面}：{人物位置}，{动作阶段}，{构图}，{场景和光线}。
```

## 一段视频：参考图视频提示词

### 总时长 ≤ 单段上限

所有分镜参考图拼接一张 1×N 图。视频 prompt：

```text
这是 {N} 个分镜的参考图，一行 {N} 张，从左到右第 {i} 张对应分镜 {i}。
这张图只作参考，不要求视频严格以某一张开始或以某一张结束。
按从左到右的顺序表现：
第 1 张（分镜 1，约 {d} 秒）：{分镜 1 内容}
...
总时长约 {total} 秒。保持人物、服装、场景、光线和色调一致；不要出现分格线、文字、水印。
```

### 总时长 > 单段上限（长视频）

按 15 秒一段切分，每段一张 1×N 参考图，写入 Extender 的 `clips_json`。每个 clip 的 prompt：

```text
subject_definitions: <Picture {n}> = 本段分镜参考图。
这是第 {i} 段的连续镜头。{本段分镜内容}。
开头延续上一段结尾的动作、镜头方向和光线；本段结尾停在 {结束状态}。
约 {d} 秒，无切镜；不要出现额外人物、文字、水印。
```

第一段不写“延续上一段”，从起始状态开始。最后一段写收束状态。

## 示例

```text
[主题与场景] 雨夜霓虹街头，一位年轻女侦探撑黑伞停在便利店门口。
[人物一致性] 黑色短发，米色风衣，深色长裤，神情冷静；保持 <Picture 2> 的五官和服装一致。
[镜头] 中景，平视，三分构图，右侧霓虹作前景遮挡，侧逆光，镜头缓慢推近。
[动作与物理] 她收起雨伞，雨水顺着伞骨滴落，风衣下摆被夜风吹动。
[风格] 写实电影感，青橙色调，35mm 胶片颗粒，浅景深。
[视频] subject_definitions: <Picture 1> = 本镜关键帧；<Picture 2> = 角色正面。
她抬头看向便利店招牌，镜头缓慢推近到面部；保持人物外观与关键帧一致。
```

## 检查

- 人物、服装、场景是否在所有关键帧/参考图之间保持一致？
- 分镜视频的 `<Picture N>` 是否按实际填槽顺序写对？
- 一段视频的拼接图是否是一行 N 张，而不是首尾帧 2×N？
- 长视频每段是否 ≤15 秒，段间是否重复上一段结尾动作？
- 是否写清景别、机位、光影和运动？
- 是否包含“不要出现”的负面约束？
- 文本引用是否使用 `{{变量名}}`，图片引用是否使用 `<Picture n>`？
