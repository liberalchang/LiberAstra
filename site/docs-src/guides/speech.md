# 语音

文字转语音、语音转文字、音色库与音乐库。

语音是独立 Provider，不在 LiberAstra 进程内。本机 Liber Speech 从「资源 → 插件」安装并启用；已经跑在别的机器上时，到服务提供方填地址。详见下文「插件」。

## 文字转语音

按服务类型出不同控件：

| 配音服务 | 音色怎么选 | 试听 |
|----------|------------|------|
| 本地 TTS（`edge_tts`） | 服务音色列表，例如 `zh-CN-XiaoxiaoNeural` | 有 |
| API TTS（OpenAI 兼容） | 服务音色列表，例如 `alloy` | 有 |
| Liber Speech | 音色库或「使用默认声音…」，并选择语言 | 无。克隆音色直接播放音色库里的参考音频 |
| ComfyUI 语音工作流 | 工作流包参数 | 无 |

试听出现在文字转语音、数字人口播、快速创作和自定义素材。输入框默认是「你好,这是一段试听语音! 」，也可以改成别的短句（最多 200 字）。点喇叭用当前音色当场合成并播放，不进入任务队列，也不保存成资产。

Liber Speech 的模型包在「系统设置 → 默认语音合成」里选择，默认 Chatterbox-Multilingual V3。功能页不选模型，只选音色和语言。语言下拉跟随当前模型包：多语言模型列出 23 种语言，单语言包只保留那一种。选音色库条目时，参考音频用来克隆音色，语言只决定 `language_id`。选「使用默认声音…」时不传参考音频。朗读语言只影响发音，不翻译正文。Turbo 和 Nano 只读英文，克隆参考音频需要长于 5 秒。

## 语音转文字

上传音/视频；语言可自动或 `zh`/`en` 等。输出按 txt、json、srt、vtt 取第一种可用。

## 音色库

本地克隆：上传参考音频 + 参考文字，`voice_id` 留空。仅云端复刻返回编号时才填 `voice_id`。

## 音乐库

BGM 上传/试听/删除；同名自动加序号。快速创作与自定义素材从这里选。
