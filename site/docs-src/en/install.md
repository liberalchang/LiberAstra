# Install / Download

This is a short install guide. For more details, see repository docs:

- `docs/deployment.en.md`
- `docs/deployment.md`

## Docker (recommended)

```bash
docker compose up -d --build
```

Open `http://localhost:8000`, create admin, then go to “Settings → Providers”.

LiberAstra does not run models; providers do (ComfyUI / Ollama / speech).
