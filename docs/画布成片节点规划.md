# 画布成片节点规划

快速创作和自定义素材仍是功能页上的整条流水线。这次画布对齐没有把它们搬进来。下面是以后若要在画布上做出同样成片，可以增加的节点。现有节点保持单一职责：一个功能节点跑一个工作流包，一个语音节点做一次文字转语音或语音转文字，一个合成节点只做首尾相接。

## 现在画布已经能接上的部分

- 文生图、图生图、图生视频、文生视频：单段画面。
- 数字人、动作迁移：时长跟随上游音频或参考视频，可分段并用尾帧衔接；动作迁移可选参考视频原声；这两类可叠音乐库里的背景音乐。
- 文字转语音、语音转文字：转写正文写入节点变量。
- 画面分析：看一张图或一段视频，写出描述，写入节点变量。
- 视频合成、音频合成：按顺序拼接，不烧字幕，不叠标题，不按口播时长裁切。

缺的是流水线中间那几步：分镜、标题卡、把成片裁到口播时长、把字幕烧进画面。

## 建议新增的节点

每个节点只做一件事，用连线把顺序固定下来。文字结果都写入该节点的变量，下游用 `{{变量名}}` 引用。

### 分镜

输入一段主题或完整文案，调用系统设置里的默认 LLM。输出一组镜头，每镜包含口播句、画面提示、建议视角（面部特写 / 正面 / 侧面 / 背面）。

快速创作里「主题 → 口播」和「口播 → 画面」是两次调用。画布上可以是同一个节点的两种模式：只写口播，或在已有口播上补画面提示。不要在这个节点里出图或出视频。

下游把每一镜的口播连到文字转语音，把画面提示连到文生图、图生视频或图生视频。角色仍用现有的角色输入节点，不在分镜节点里再选一次人。

### 标题卡

输入标题、画幅和停留秒数（默认约 2 秒）。输出一段无口播的短视频，风格与功能页标题卡相同：渐变底、居中标题。

它接在视频合成的第一段。不负责后面的素材。

### 口播对齐

输入一条画面视频和一条音频。把视频裁到音频时长；视频短于音频时不拉慢画面，按功能页现在的做法用静音或停在最后一帧把时长补齐（实现时沿用自定义素材里已有的裁切，不另写一套时间规则）。

自定义素材的「素材动画」就是：图生视频先按模型出一段，再裁到这一句口播的长度。画布上应是「图生视频 → 口播对齐」，而不是在图生视频节点里隐藏这次裁切。图生视频功能页本身仍由用户设定秒数。

### 字幕

输入一条视频，以及一句文案或一条字幕文件（srt / vtt）。把字幕烧在画面底部。字号、颜色与功能页相同：0 为自动，默认白色。

语音转文字已经能导出 srt / vtt。字幕节点吃这个文件，或直接吃分镜节点的一句口播并按音频时长铺成一条字幕。不要在合成节点里顺便烧字幕，否则只想拼接的画布会被迫带字幕。

## 两条成片怎么连

快速创作（视频模式）大致是：

1. 分镜：主题或文案变成多句口播和画面提示。
2. 每一句：文字转语音；文生图或图生视频（选了角色时用角色输入）。
3. 口播对齐：图生视频裁到这一句音频。
4. 字幕：可关。
5. 标题卡可放在最前。
6. 视频合成按镜号接成一条。背景音乐仍用数字人 / 动作迁移上已有的音乐库控件；若成片节点本身不是这两类，合成之后需要单独的「混音」节点，见下文。

自定义素材大致是：

1. 图片或视频输入先进画面分析。
2. 分镜按分析结果写每镜口播。
3. 图片镜：文字转语音后，用现有的静图加音频做成一段（这一步今天在功能页里，画布还没有「静图成片」节点，可与标题卡同类，输入图、音频和时长）。
4. 视频镜：素材原片，或图生视频后再口播对齐。
5. 字幕、标题卡、视频合成，与上面相同。

## 先不要做的

- 不要把快速创作或自定义素材做成一个巨大的功能节点。功能页可以继续作为一键成片；画布上的价值是能换掉其中一段。
- 不要在图生视频节点里自动裁到口播时长。那是口播对齐节点的事。
- 背景音乐今天挂在数字人和动作迁移上，因为这两类在功能页上就有。合成之后的成片若也要叠音乐，再加一个只做混音的节点，输入视频和音乐库曲目。不要把混音塞进视频合成。
- 分镜模板（卡片排版）仍留在快速创作功能页。画布第一期只出视频条，不重做模板渲染。
