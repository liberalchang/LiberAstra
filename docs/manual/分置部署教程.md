# LiberAstra 分置部署教程

适用场景：**应用主机**只跑 LiberAstra（Web + API + SQLite/数据目录），**显卡主机**跑 Ollama / ComfyUI / Liber Speech。两边通过局域网 HTTP 互联。

本文不包含任何主机登录密码；请自行用 SSH / 堡垒机管理。

---

## 架构示意

```
┌─────────────────────────────┐         LAN          ┌──────────────────────────────┐
│ 应用主机（如 10.10.17.235）  │◄───────────────────►│ 显卡主机（如 10.10.12.140）   │
│                             │                      │                              │
│  LiberAstra (Docker)        │   HTTP 调用 Provider │  Ollama      :11434          │
│  发布端口 18000→容器 8000   │                      │  ComfyUI     :8188           │
│  数据卷 ./data → /data      │                      │  Liber Speech:5555           │
└─────────────────────────────┘                      └──────────────────────────────┘
```

在 LiberAstra「服务提供方」中配置：

| 名称示例 | 类型 | Base URL 示例 |
|----------|------|----------------|
| comfy | ComfyUI | `http://10.10.12.140:8188` |
| ollama | Ollama | `http://10.10.12.140:11434` |
| speech | Liber Speech API | `http://10.10.12.140:5555` |

容器已配置 `extra_hosts: host.docker.internal:host-gateway`；访问**另一台机器**时直接用对方局域网 IP，不要用 `localhost`。

## 一、仅部署 LiberAstra（应用主机）

### 1. 拉取代码

```bash
cd /home/<user>/workspace   # 或你的工作目录
git clone https://github.com/liberalchang/LiberAstra.git
cd LiberAstra
# 已有仓库则：
git pull --ff-only
```

### 2. 环境变量

```bash
cp .env.example .env
```

常用项：

| 变量 | 说明 |
|------|------|
| `LIBERASTRA_SECRET_KEY` | 生产建议显式设置；若从旧环境迁数据，**必须保留原 `data/.secret_key`**，否则已加密的 Provider API Key 无法解密 |
| `LIBERASTRA_DATABASE_URL` | 留空 = SQLite（`data/liberastra.db`） |
| `LIBERASTRA_PUBLISH_PORT` | 宿主机发布端口，默认 `8000`。若 8000 已被其它容器占用，改为 `18000` 等 |

示例（宿主机用 18000）：

```bash
echo 'LIBERASTRA_PUBLISH_PORT=18000' >> .env
```

`docker-compose.yml` 中映射为：`${LIBERASTRA_PUBLISH_PORT:-8000}:8000`（左侧宿主机，右侧容器内固定 8000）。

### 3. 启动（不要开 ollama/comfyui/speech profile）

```bash
docker compose up -d --build
docker compose ps
curl -sf http://127.0.0.1:${LIBERASTRA_PUBLISH_PORT:-8000}/healthz
# 期望：{"status":"ok","version":"..."}
```

浏览器访问：`http://<应用主机IP>:<发布端口>`。

### 4. 常用运维

```bash
cd /path/to/LiberAstra
docker compose logs -f --tail 100
docker compose restart
docker compose pull   # 若改用远程镜像时
docker compose down   # 停止（不删 ./data）
```

数据目录：`./data`（SQLite、outputs、uploads、voices、workflows、prompts、`.secret_key` 等）。**不要把 data 放进网盘同步目录。**

## 二、迁移已有 data / 数据库

从开发机或旧主机迁到应用主机时，务必整包迁移（含密钥）：

1. **停写**：旧实例先停服务或停写入，避免 SQLite 半截写入。
2. **打包**（在旧机器，数据目录为 `backend/data` 或 Docker 的 `./data`）：

```bash
# 示例：排除日志与 SQLite 临时文件
tar -czf data-migrate.tgz \
  --exclude=logs \
  --exclude='liberastra.db-shm' \
  --exclude='liberastra.db-wal' \
  -C /path/to/data .
```

3. **传到新主机**并解压到仓库根目录的 `data/`（与 compose 的 `./data:/data` 一致）：

```bash
cd /path/to/LiberAstra
docker compose down
mkdir -p data
tar -xzf data-migrate.tgz -C data
# 确认：
ls data/liberastra.db data/.secret_key
docker compose up -d
```

4. **校验**：登录原管理员账号；「服务提供方」里 Base URL 是否仍指向显卡主机；试一次 LLM / 出图 / TTS。

> 只拷 `liberastra.db` 不拷 `.secret_key`，会导致已保存的 API Key 解密失败。

## 三、显卡主机：各服务分别部署

LiberAstra 主 compose 的 `ollama` / `comfyui` / `speech` 为 **profile 可选**；分置时一般在显卡主机**各自独立安装**，不必在应用主机 `docker compose --profile ...`。

### 1. Ollama

官方安装或 Docker 均可，监听 `0.0.0.0:11434`，放行局域网。

```bash
# Docker 示例
docker run -d --name ollama --gpus all -p 11434:11434 \
  -v ollama:/root/.ollama ollama/ollama
# 拉取模型后，在 LiberAstra 添加 Ollama Provider，Base URL = http://<显卡IP>:11434
```

### 2. ComfyUI

按现有环境安装（本仓库可选 profile 使用 `yanwk/comfyui-boot`）。需：

- 监听可被应用主机访问（如 `0.0.0.0:8188`）
- 安装 LiberAstra 工作流所需自定义节点与模型（见工作流包 `requirements`）

LiberAstra Provider：`ComfyUI`，Base URL = `http://<显卡IP>:8188`。

### 3. Liber Speech（语音）

仓库内独立目录，可在显卡主机单独 compose：

```bash
# 在 LiberAstra 源码树中
cd services/speech
docker compose up -d --build
# 默认 :5555，需 NVIDIA Container Toolkit
```

LiberAstra Provider：类型选 Liber Speech API，Base URL = `http://<显卡IP>:5555`。若设置了 `LIBER_SPEECH_API_KEY`，两边一致。

### 4. 网络与防火墙

- 应用主机 → 显卡主机：放行 `11434` / `8188` / `5555`（按实际启用的服务）
- 显卡主机上的服务绑定 `0.0.0.0`，不要只绑 `127.0.0.1`
- 从应用主机测试：

```bash
curl -sf http://10.10.12.140:11434/api/tags | head
curl -sf http://10.10.12.140:8188/system_stats | head
curl -sf http://10.10.12.140:5555/healthz || curl -sf http://10.10.12.140:5555/docs | head
```

## 五、与「一键全栈」的区别

| 方式 | 命令 | 适用 |
|------|------|------|
| 仅 LiberAstra | `docker compose up -d --build` | 推荐：AI 能力在别的机器 |
| 本机再挂 Ollama | `docker compose --profile ollama up -d` | 单机试用 |
| 本机再挂 ComfyUI | `docker compose --profile comfyui up -d` | 需本机 NVIDIA |
| 本机再挂 Speech | `docker compose --profile speech up -d` 或 `cd services/speech && docker compose up -d` | 需本机 NVIDIA |
| PostgreSQL | `--profile postgres` + 设置 `LIBERASTRA_DATABASE_URL` | 可选 |

更短的通用说明见 [deployment.md](./deployment.md)。
