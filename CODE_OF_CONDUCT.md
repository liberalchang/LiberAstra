# 行为准则

[English](#english)

参与 Issue、Discussion、Pull Request 时：

- 对事不对人。批评针对具体行为和改动。
- 不发布他人的密钥、私人数据或未同意的生成内容。
- 接受维护者对无关广告、人身攻击和重复刷屏的关闭。

感到被骚扰时，开一个公开 Issue 并 @liberalchang，或用 [安全通报](https://github.com/liberalchang/LiberAstra/security/advisories/new)（适合不适合公开的内容）。维护者会决定警告、暂时限制互动，或交给 GitHub 处理。

## English

Discuss the change, not the person. Do not post anyone else's secrets, private data, or generated media they did not agree to share. Maintainers may close ads, insults, and spam.

To report harassment, open an issue mentioning @liberalchang, or use a [private security advisory](https://github.com/liberalchang/LiberAstra/security/advisories/new) when the report itself should stay private.
