# 图像

本页为图像相关能力的导览与指引，详细章节可在仓库文档中查阅或搜索：

- `docs/使用文档.md`（体量较大，建议分章节阅读）

## 生成（Generate）

- 在主页使用 `PromptField` 输入文字描述，选择图像工作流
- 任务会进入队列，可在结果面板预览

## 编辑（Edit）

- 选择需要编辑的图片，进入编辑工作流（如 Inpaint / ControlNet 等）
- 根据工作流的 UI 选择遮罩、参考图与参数

## 画布（Canvas）

- 在「画布导演台」中可以对多个元素进行排版与再编辑  
  参考：`docs/画布导演台.md`
