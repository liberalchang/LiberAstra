# 画布功能固定与资源归类开发计划

> 状态：开发完成（2026-11-04）。画布功能固定、通用节点保留、素材库「工作」页签、导航归类与分镜模板迁移均已实现；后端/前端测试、构建和浏览器验收通过。
> 范围：画布节点功能语义、通用节点保留、素材库「工作」页签、导航与路由归类、模板改名。
> 不在本期范围：Asset 存储模型改造、换音附属文件合并、通用节点 UI 创建入口、旧路由重定向、模板编辑器。

## 背景

前几轮讨论确认了四个方向：

1. 画布节点的「功能」应在创建时确定，不再提供功能切换。用户真正需要切换的是功能内的工作流或模型。
2. 文生图/文生视频不自动补文本输入节点。文本是节点参数，不是必须连线的媒体槽。
3. 素材库新增「工作」页签，按 `job_id` 聚合一次任务产出的全部资源；默认仍是「全部」扁平列表。
4. 导航按「创作 / 资源 / 任务 / 设置」重新归类；「模板管理」改名为「分镜模板」并移到设置。

## 已对齐的决策

1. **功能创建时固定**：UI 和 agent 都不再做功能间切换；同一功能内可以切换工作流、模型、服务商。
2. **语音节点不切 mode**：TTS / ASR / VC 在创建时确定；语音节点自动补建必填媒体输入的逻辑保持不变。
3. **文本输入不自动补建**：`ensureSlots()` 继续跳过 `text` 槽；文本节点仍可手动创建并接入。
4. **通用节点保留**：无 `presetId`、但有 `pack` 或 `targetType/targetId/providerId` 的功能节点继续可用。它由 agent/API 创建和绑定，本期不增加 UI 创建入口。
5. **旧空功能节点不做兼容**：没有 `presetId` 也没有 `pack/target` 的空功能节点不再提供「绑定功能」下拉；画布中提示未绑定，由用户删除后重新创建。
6. **素材库「工作」页签**：标签为「工作」，放在「全部」之后，默认仍为「全部」。按 job 聚合，不改变现有 Asset 模型。
7. **路由直接重置**：本地项目，不做旧路由重定向；旧地址失效可以接受。
8. **分镜模板**：原「模板管理」改名「分镜模板」，移到设置；快速视频页增加轻量「管理模板」入口。

## 一、画布节点功能固定

### 1.1 标题显示真实功能

- 统一使用 `nodeTitle()` 生成节点标题，画布卡片和属性面板标题共用同一结果。
- 输入节点：图片输入 / 文本输入 / 角色输入 / 视频输入 / 音频输入。
- 工具节点：图片拼接 / 视频拼接 / 音频拼接。
- 语音节点：文字转语音 / 语音识别 / 音色替换。
- 功能节点：优先 `presetTitle`，其次 `pack` 名称，再其次 `targetId`，最后才显示「通用节点」或「功能节点」。
- 属性面板左上角不再显示笼统的「输入节点」「工具节点」「功能节点」。

验收：任意节点选中后，标题能直接看出当前功能；通用节点显示其工作流或「通用节点」。

### 1.2 移除功能切换控件

- `PresetInspector.tsx`：
  - 删除顶部「切换功能」下拉。
  - 保留功能标题、服务商、模型/工作流下拉。
  - 切换服务商或目标时继续调用 `applyMenuToNode()`，只补建缺失输入，不改变 `presetId`。
  - 服务商/模型/工作流候选仍由画布菜单设置决定：`specsForMenu()` 按 `sub_capability`、`bind_mode`、`manual_targets` 过滤，`resolveSpec()` 优先 `default_target`；手动指定只显示勾选项，自动匹配显示该能力下全部已启用目标。不绕过菜单设置直接列全局模型。
- `NodeInspector.tsx` 的 `FunctionInspector`：
  - 删除未绑定节点的「选择功能…」下拉。
  - 保留 `pack` 分支：输入槽、提示词、参数、高级设置、加速等全部继续渲染。
  - 无 `presetId`、无 `pack/target` 的节点显示「未绑定执行目标」提示，不提供功能选择。
- `SpeechInspector`：
  - 不提供 TTS / ASR / VC 模式切换。
  - 保留现有服务商、模型、音色、字幕、格式等配置。
  - 语音节点自动补建输入连线逻辑不变。
- 图片/视频功能节点：不再允许从属性面板改成另一个功能；需要换功能时新建节点。

验收：属性面板中不存在功能切换下拉；模型/工作流下拉仍可用；切换目标后缺失输入仍会自动补建。

### 1.3 通用节点保留

通用节点定义：`kind="function"`、没有 `presetId`，但已有以下任一绑定：

- `pack`（直接绑定的工作流包）；或
- `targetType` + `targetId`（+ `providerId`，直接绑定的模型或工作流）。

实现要求：

- `FunctionInspector` 不得因为缺少 `presetId` 而隐藏 `pack` 输入槽、提示词和参数区域。
- 属性面板显示只读「执行目标：<pack/target>」；本期不增加通用节点的 UI 创建入口，也不增加通用节点更换目标的 UI。
- agent/API 仍可通过 `canvas_add_node(kind="function")` + `canvas_apply_pack` 或直接写 target 创建通用节点。
- 旧的无绑定空功能节点不做兼容；属性面板提示未绑定，建议删除后从菜单新建。

验收：导演台可以创建空白功能节点并绑定工作流；节点标题和属性面板正常显示执行目标；普通 UI 不提供通用节点创建按钮。

### 1.4 Agent 与工具约束

必须让 agent 行为和 UI 一致：

- `frontend/src/director/clientTools.ts`：
  - `canvas_apply_menu` 只允许用于没有 `presetId`、没有 `pack/target` 的空白功能节点或语音节点；节点已有功能时拒绝，并提示「功能在创建时确定，请新建节点」。
  - `canvas_apply_pack`：
    - 有 `presetId` 的功能节点，只允许绑定该菜单项 `available_targets` 中允许的工作流；
    - 无 `presetId` 的通用节点，允许绑定任意工作流包。
  - `EDITABLE_FIELDS.speech` 移除 `"mode"`，禁止 `canvas_update_node` 直接改语音模式。
  - `canvas_add_node` 的空功能节点创建路径保留，不新增 UI 入口。
- `backend/liberastra/agent/skills/canvas-auto/SKILL.md`：
  - 明确「换功能新建节点，换工作流/模型在当前节点换目标」。
  - 保留「没有合适菜单时 `list_workflows` + `canvas_apply_pack`」的通用节点路径。
  - 说明空功能节点只用于首次绑定，不用于后续功能切换。
- `backend/liberastra/agent/skills/director/SKILL.md`：
  - 同步上述规则；
  - 保留特定功能的 `available_targets` 选包流程（如 Union Depth、姿势生图），但不得跨功能套用菜单。
- `backend/liberastra/agent/skills/project-info/references/node-parameters.md`：
  - 更新 `presetId`、`pack`、`targetType` 字段说明和通用节点示例。

验收：

- 对已有功能的节点再次 `canvas_apply_menu` 到另一个功能会返回明确错误；
- 同一功能内通过 `canvas_apply_pack` 换允许的工作流仍然成功；
- agent 不能再通过 `canvas_update_node` 改 speech mode；
- 导演台/画布 skill 的现有建节点、补输入、绑工作流流程不回归。

### 1.5 测试

- 前端单测或客户端工具测试：功能切换拒绝、同功能换包允许、语音 mode 不可编辑、通用节点可绑包。
- 浏览器验证：
  - 输入/工具/语音/功能节点标题正确；
  - 属性面板没有功能切换控件；
  - 切换工作流/模型仍会补建必要输入；
  - 语音节点从菜单创建后自动补建媒体输入；
  - 导演台创建通用节点并绑工作流后，节点可正常显示和执行。

## 二、素材库「工作」页签

### 2.1 后端接口

现有 `GET /api/v1/assets` 只返回最近 50 条扁平资源，前端按 `job_id` 分组会得到不完整文件夹。新增服务端聚合接口。

新增 `GET /api/v1/assets/jobs`：

查询参数：

- `limit`：默认 20，最大 100；
- `offset`：默认 0；
- `job_kind`：可选，按任务类型筛选。

返回 `AssetJobOut[]`：

```json
{
  "job_id": "uuid",
  "job_kind": "vc.convert",
  "created_at": "2026-11-04T21:58:00",
  "asset_count": 3,
  "kinds": ["audio", "subtitle"]
}
```

规则：

- 只统计当前用户、`job_id` 非空、`hidden=false` 的 Asset；
- 按 job 的 `created_at` 倒序；
- `kinds` 去重，用于文件夹卡片上的类型标记；
- 没有可见资源的 job 不返回；
- 不新增数据库迁移；`assets.job_id` 已有索引；
- 路由声明顺序要把 `/jobs` 放在 `/{asset_id}` 之前，避免被资源详情路由截获。

扩展现有 `GET /api/v1/assets`：

- 增加 `job_id` 过滤；
- 增加 `offset` 分页；
- 增加 `limit` 上限保护；
- 继续默认排除 `hidden`。

文件夹详情复用该接口，例如：

```text
GET /api/v1/assets?job_id=<job_id>&limit=50&offset=0
```

### 2.2 前端「工作」页签

- `AssetsPage` 页签顺序：

  ```text
  全部 / 工作 / 图片 / 音频 / 视频 / 字幕 / 文本
  ```

- 默认仍选中「全部」，保持现有扁平列表。
- 「工作」页签请求 `/assets/jobs`，显示文件夹网格：
  - 文件夹图标；
  - 标题用时间，例如 `11-04 21:58`；跨年时显示年份；
  - 副标题用任务类型 + 文件数，例如 `音色替换 · 3 个文件`；任务类型名称复用任务页已有的 job kind 文案，抽成公共 helper，避免两处各写一份；
  - 右侧数量角标；
  - 类型小标记（audio / subtitle / video / image）；
  - **不请求任何媒体缩略图或完整文件**。
- 点击文件夹进入详情：
  - 路由建议 `/assets/jobs/:jobId`；
  - 顶部显示任务类型、完整时间、文件数，并提供「查看任务」链接到任务详情；
  - 资产列表复用现有 `MediaThumb`；图片/视频点击打开现有 `MediaLightbox`；
  - 音频使用现有播放器；
  - srt/vtt 显示为字幕行，点击后才读取文本或下载；
  - 详情内分页或懒加载，不一次拉取全部资产；
  - 本期不做文件夹级删除，单文件删除保持现状。
- 「工作」页签内搜索只过滤已加载的文件夹（任务类型/时间）；详情内搜索按资产名称/类型过滤。

### 2.3 加载与性能约束

- 文件夹列表只查 job 元数据和资源计数，不生成缩略图。
- 文件夹详情才挂载 `MediaThumb`；视频缩略图继续走现有缩略图接口，不加载完整视频。
- 字幕只在用户点击预览时读取内容。
- 分页使用 `limit/offset`，不在前端一次性拉取全部资源。

### 2.4 测试

- 后端：
  - 同一 job 的 audio + srt + vtt 归入一个文件夹；
  - `hidden=true` 的画布临时资源不出现；
  - 无资源的 job 不出现；
  - 分页和 `job_kind` 过滤正确；
  - `job_id` 过滤只返回该任务的可见资产。
- 前端/浏览器：
  - 默认仍是「全部」；
  - 「工作」页签显示文件夹；
  - 文件夹列表不产生媒体缩略图请求；
  - 点进文件夹后图片/视频缩略图、音频播放、字幕下载正常；
  - 换音任务的音频、srt、vtt 显示在同一个文件夹内。

## 七、风险与取舍

- **旧空功能节点**：不做兼容，旧画布可能留下不可执行的空节点；由用户删除后重建。若实际旧数据较多，再单独做一次清理或提示迁移。
- **agent 习惯**：现有 skill 可能仍尝试「先建节点再换功能」；必须同步改 skill 并加工具校验，否则会出现 UI 不允许但 agent 能做的行为。
- **同功能换包**：`canvas_apply_pack` 的校验要允许同一功能的可用目标（如 Union Depth），不能一刀切禁止，否则会破坏现有导演台流程。
- **工作页签性能**：必须服务端聚合，不能前端对最近 50 条资产分组；文件夹详情也要分页。
- **附属文件仍出现在「全部」**：本期不做附属资源合并，srt/vtt 仍会作为独立资产出现在扁平列表；「工作」页签只提供聚合视图。
- **路由失效**：本地项目接受旧地址 404；如果以后有外部文档或分享链接，再补重定向。
