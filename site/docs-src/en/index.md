# LiberAstra Orchestration Desk

**Tagline**: Orchestrate, don't infer.

LiberAstra is a self-hosted AIGC orchestration desk. It unifies ComfyUI, Ollama, speech services, and OpenAI-compatible APIs on one desk:

- **Access**: Web UI, `astra` CLI, MCP, OpenAI-compatible `/v1`
- **Important premise**: LiberAstra does not run models; it only orchestrates. Models actually run in ComfyUI / Ollama / speech services.
- **Brand tone**: dark and light themes are equal citizens; Chinese and English are equal citizens; honest, tool-like voice.

## Who it is for

- Developers and creators who need to unify image / video / speech capabilities in a local or private environment
- Teams that need coordinated orchestration across **Web/CLI/API** entry points

## Non-goals

- It is not a model runtime container and does not reinvent the inference executor
- It does not fabricate "cases, users, scores, or download counts"
