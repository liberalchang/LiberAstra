# 全局提示词优化与场景模板库开发计划

> 状态：实施中。目标：系统级默认 LLM、统一 PromptField UI、按功能/场景的可定制提示词库。

## 背景与问题

1. 文生图仅有星号按钮调用 LLM 优化，多 LLM 时无法指定服务商/模型。
2. 快速创作自带 LLM 选择器与「画面提示词优化」开关，与其它页面不一致。
3. 图生图、图生视频、动作迁移等提示词入口无优化能力。
4. 优化 system prompt 过于简单，未按任务类型与工作流包区分。

## 架构

- **系统设置**：`default_llm_provider_id` + `default_llm_model`（`app_settings`）。
- **统一组件**：`PromptField`（原始 / 优化双 Tab、场景下拉、✨ 覆盖生成、使用优化开关、过期提示）。
- **提示词库**：`backend/prompts/` 内置种子 → 首次启动同步到 `data/prompts/`（用户可改/导入）。
- **API**：`GET/PUT /api/v1/prompts`、`POST /api/v1/prompts/optimize`（旧 `/images/optimize-prompt` 兼容转发）。

## 任务类型（task）

| id | 用途 |
|----|------|
| `t2i` | 文生图 |
| `i2i` | 图生图 / 局部重绘 |
| `upscale` | 修复放大约束词 |
| `i2v` | 图生视频 / 素材动画 |
| `t2v` / `quick_visual` | 文生视频 / 快速创作画面提示词 |
| `motion` | 动作迁移 |
| `quick_topic` / `assets_topic` | 短视频主题扩写 |

## 场景预设（scene）

`auto` / `photo` / `poster` / `illustration` / `product` / `character` / `infographic` / `architecture` / `cinematic_video`

参考：[benyshen/awesome-image-prompts](https://github.com/benyshen/awesome-image-prompts) 六槽位协议；[dongshuyan/Awesome-Prompts](https://github.com/dongshuyan/Awesome-Prompts) 意图解析与多态细节。

## PromptField 交互要点

1. 双缓冲：`raw` / `optimized` / `optimizedFromRaw`。
2. ✨ 始终以当前原始输入调用优化并**覆盖**右侧。
3. 原始变更后右侧标「已过期」，不自动清空。
4. `useOptimized && optimized` 时任务提交用优化后文本。

## 工作流上下文

优化时若传 `workflow`，注入包 capability、描述、模型家族（`minimax_h3` / `qwen_image` / `sd*`）及是否含 Guide enhancer。

## 接入页面

文生图、图生图、修复放大、图生视频、动作迁移、快速创作（移除旧 llmPicker/optimizeVisuals）、自定义素材（主题 + 动画提示词）。

## 验收

- 系统设置可保存默认 LLM；未选页面级 LLM 时优化与脚本均走默认。
- 各提示词入口统一 UI；开关决定提交用原文还是优化稿。
- `data/prompts/*.yaml` 可手工编辑并被下次优化使用。
