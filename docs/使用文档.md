# LiberAstra 使用文档

LiberAstra 是本机的编排界面。出图、出声都交给已经配好的外部服务，本机不内置模型。

## 打开方式

生产环境只启动后端。先在 `frontend` 里执行过一次 `npm run build`，再在 `backend` 里执行：

```powershell
uv run astra serve --reload
```

浏览器打开 `http://127.0.0.1:8000/`。8000 同时提供接口和已经打包好的页面。

改界面时另开前端开发服务器，地址是 `http://127.0.0.1:5173/`。5173 跑的是源码，页面里的 `/api` 会转到 8000。8000 上的页面要重新 `npm run build` 才会跟上源码。

侧栏「使用文档」就是本文。一个账号可以同时在多个浏览器登录，每次登录各自拿到一张令牌，有效期 12 小时。过期后页面会自动退回登录页，重新登录即可。

## 服务提供方

Provider（服务提供方）是一条保存下来的外部服务。在「设置 → 服务提供方」里添加，填写名称、类型、地址和能力。已添加的 Provider 可以点「编辑」修改名称、地址、密钥和启用状态，API Key 留空表示保持不变。

地址用 `http://`。把本地服务的端口写成 `https://` 会协议错误。ComfyUI 的 API Key 留空。语音服务如果设了 `LIBER_SPEECH_API_KEY`，把同一个 Key 填到这条 Provider 里。

页面上的「图像服务」「语音服务」「识别服务」都是在选 Provider。只列出已启用、且能力匹配的条目。图像能力是 `image`，朗读是 `tts`，识别是 `asr`。

工作流包决定用这台 ComfyUI 上的哪套模型和哪张计算图。Provider 只决定请求发到哪台机器。

## 文生图

侧栏打开「图像 → 文生图」。工作流包选 `qwen_image_21` 时模型文件名写在包里，页面不用填模型；选 `t2i_basic` 时从下拉框选 ComfyUI `checkpoints/` 里的文件（推荐分组会把与包同家族的排在前面）。

提示词用自然语言长句，右侧按钮会用已配置的 LLM 改写这段文字。宽、高、步数、种子、张数按页面默认即可；种子 `-1` 表示每次随机，一次出多张时从这颗种子起逐张加 1。

## 图生图与编辑

侧栏打开「图像 → 图生图与编辑」。LiberAstra 把工作流包里的 API JSON 直接提交给 ComfyUI，Comfy 网页上不用另建画布。

- **整图编辑**（如 `qwen_image_21_edit`）：只上传一张原图。提示词写成编辑指令，写明留什么、改什么，例如「保持人脸和姿势，把背景换成中式庭院」。这类模型会重画整张图，没点名的区域也可能轻微变化。
- **局部重绘**（如 `qwen_image_21_inpaint`）：按顺序上传两张——先原图后蒙版，不能反。白色是要重画的地方，黑色保持原图。蒙版要事先做好再上传，页面上没有画笔。`grow` 把白区向外扩一圈，避免接缝留旧内容。换背景、换衣服、改一只手建议分三次，每次只涂一块。

上传区支持多选、分多次添加，缩略图条可以单独删除传错的图；原图和蒙版缩略图上有角标区分。

## 修复与放大

侧栏打开「图像 → 修复与放大」，工作流包 `upscale_basic`。用 ComfyUI 的 `UpscaleModelLoader` + `ImageUpscaleWithModel`，宽和高各放大 4 倍，不是生图。模型文件要放在 ComfyUI 的 `upscale_models` 目录。提示词可以留空，这条工作流不读提示词。

## 语音

语音服务是独立的 Provider，不在 LiberAstra 进程里。文字转语音和语音转文字都选对应能力的 Provider。

### 文字转语音

配音服务按类型出不同控件：本机 edge_tts 和第三方 TTS 出**服务音色列表**（自动拉取，可刷新）；Liber Speech 出**音色库**（参考音频克隆）；存在 tts 工作流包时可以选 ComfyUI，走语音工作流。朗读语言只决定发音方式，不会把文字翻译成另一种语言。输出格式 mp3 通用，wav / ogg 取决于服务。

### 音色库

本地克隆：上传参考音频，填写这段音频里说的文字，`voice_id` 留空。`voice_id` 只在云端复刻服务返回了音色编号时才填，不要填 `1` 这种序号。

### 音乐库

背景音乐的上传、试听和删除。上传即入库，同名自动加序号不覆盖。快速创作和自定义素材的背景音乐从这里选。

### 语音转文字

上传音频或视频。语言可选自动检测，或填 `zh`、`en` 这类代码。输出按 txt、json、srt、vtt 顺序取第一种可用格式。

## 视频

侧栏里有快速创作、自定义素材、数字人口播、图生视频、动作迁移、模板管理。

### 快速创作

一句话或一段文案出一条短视频：AI 写口播 → 拆分镜 → 逐镜配音+画面 → 拼接混音。页面分四块：

1. **视频脚本**：AI 创作（主题即视频标题，AI 写口播）/ 固定文案（标题 + 原文案按行切分）/ 批量创作（一行一个主题，每个主题一个任务，排队执行，失败互不影响）。「生成分镜后暂停」可以先出脚本和分镜 JSON，人工改完再合成。
2. **分镜模板**：先选模式再选模板——静态样式（本地排版渲染，最快）、生成插图（逐镜 AI 出图注入模板）、生成视频（逐镜跑 t2v 工作流，最慢）。选中后折叠成摘要卡，「更换模板」重新展开。文字与字幕区可分别控制模板标题/模板文案的显隐和字号倍率、底部字幕条的开关/字号/颜色。
3. **配音合成**：服务下拉按类型分流（同文字转语音）。
4. **背景音乐**：音乐库选择 + 音量（建议 0.1–0.3）。

### 自定义素材

把已有的图片/视频素材拼成带口播和字幕的短片：**不生成新画面**（除非开素材动画），画面全部来自上传的素材。适合产品图、活动照片、已有片段的解说视频。

1. **素材**：图片（JPG/PNG/WebP/GIF）和视频（MP4/MOV/AVI/WebM）混传，顺序即分镜顺序；视频素材会循环或截断对齐配音时长。
2. **素材分析**：可选。开启后先用视觉模型逐素材生成内容描述，写文案的 AI 参考真实内容而不是只看文件名。需要 ComfyUI 装 ComfyUI-AILab 插件与 Qwen-VL 视觉模型。
3. **文案与标题**：标题填了会在片头加 2 秒标题卡；主题生成文案时 AI 按"目标时长"控制文案长度。
4. **素材动画**：静态图片先经 i2v 工作流动画化再合成，每张图一次图生视频，较慢；视频素材不受影响。
5. **配音**、**画幅与背景音乐**：同上。

### 数字人口播

人物图 + 口播文案 → 先 TTS 出语音，再交给数字人工作流。配音服务按类型分流（同文字转语音）。

### 图生视频

首帧图片 + 提示词 + i2v 工作流包。宽高比按比例一次设置，两边自动吸附包声明的倍数（MiniMax 系 32，Wan 系 16）；时长按秒设置，帧数自动换算并按包声明的对齐规则吸附（如 MiniMax 的 17k+5）。选错模型类（比如用平面图像模型跑视频工作流）会在任务中心得到中文提示。

### 动作迁移

参考视频（≤30s）提供动作 + 目标图片（如人物三视图定装照）提供角色，输出"这个角色做这套动作"的视频。需要本地 Comfy 装有 SCAIL / Wan-Animate 类节点和模型，并把调好的图导入为 `motion` 能力的工作流包。

### 模板管理

分镜模板的浏览、上传与删除。模板是带 `{{占位符}}` 的 HTML 文件，文件名前缀标识类型（`static_` 静态 / `image_` 插图 / `video_` 视频），画布尺寸须与画幅目录一致。内置模板不可删，用户上传的同名会盖住内置。

## 工作流包

这些包是 LiberAstra 发给 ComfyUI 的 API JSON，不是 ComfyUI 安装后自带的菜单，也不是在线图像 API 的通用参数。

能力标签决定包出现在哪一页，规范词表：`t2i` 文生图，`i2i` 图生图，`upscale` 放大，`t2v` 文生视频（快速创作·视频），`i2v` 图生视频，`avatar` 数字人，`motion` 动作迁移，`tts` 语音，`analysis` 素材分析。

内置包在 `backend/workflows/`，用户包在 `backend/data/workflows/`，同名时用户包盖住内置包。包声明了但服务上没有的模型文件，选中时页面会给出黄色提示（只警告不拦截）。

在 ComfyUI 里用 Save (API Format) 导出的 JSON 可以在「设置 → 工作流包」导入。画布保存的那份带 `nodes` / `links` 的 JSON 不能直接当工作流包。

## 系统设置

侧栏底部齿轮或「设置 → 系统设置」：

- **账户与安全**：查看当前账户、修改密码（要验证当前密码）。
- **运行参数**：ComfyUI 等待超时（大图/视频排队时调大）、接口同步等待超时、LLM 请求超时，保存后下一个任务生效；「同主机服务串行执行」默认关闭（并行），开启后同一台主机上的多个服务同时只跑一个任务，避免抢显存。

## 文件放在哪

后端从 `backend` 目录启动时：

- 数据库：`backend/data/liberastra.db`
- 生成的文件：`backend/data/outputs/`
- 上传的文件：`backend/data/uploads/`
- 用户工作流包：`backend/data/workflows/`
- 用户模板：`backend/data/templates/`
- 音乐库：`backend/data/bgm/`

生成时切到别的页面，任务不会停。回到原页面，同一个浏览器标签会继续显示进度。关掉标签后进度条不再自动挂上，任务本身仍在。「任务」页看状态，成功的产物在「资产」。注意：任务页的「重试」复用旧参数，改了设置要发新任务。

`backend/data` 不要放进网盘或各类同步目录。同步程序锁住数据库时，接口会报 `disk I/O error`。
