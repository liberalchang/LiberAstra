# 功能迁移优化方法

把参考项目（Pixelle-Video 等）的功能迁移到 LiberAstra 的标准流程。以「自定义素材」为样例沉淀，适用于数字人口播、图生视频、动作迁移及后续功能。

## 流程

### 1. 读参考项目，拆出功能链路

- 入口：`web/pages` / `web/components`（界面有哪些配置项）、`web/i18n/locales/zh_CN.json`（每项的用途说明文案）;
- 流水线：`pixelle_video/pipelines/*.py`（阶段顺序、每阶段输入输出）;
- 服务层：`pixelle_video/services/*`（分析、合成、视频生成等各用什么协议/工作流）;
- 产出一张**功能对照表**：参考有什么、我们有没有、差距在哪。

### 2. 把参考能力映射到我们的基建，而不是照搬代码

| 参考项目概念 | LiberAstra 对应基建 |
| --- | --- |
| 服务配置（RunningHub/SelfHost/云端 API） | Provider（服务提供方）+ 能力声明（image/video/tts/llm/asr/analysis） |
| 工作流 JSON（selfhost/runninghub 目录） | 工作流包（`backend/workflows/` 内置 + `data/workflows/` 用户，manifest 声明 capability 与参数映射） |
| 模板（templates/画幅/static_/image_/video_） | 分镜模板（`backend/templates/` + `data/templates/`，Playwright 渲染） |
| 超时/并发等运行参数 | `app_settings` 运行时偏好 + 系统设置页 |
| 背景音乐目录（bgm/） | 音乐库（`data/bgm/` + `/api/v1/bgm`） |

原则：**能力驱动**。页面按 Provider 能力和包 capability 精确筛选（`t2i/i2i/upscale/t2v/i2v/avatar/motion/tts/analysis`），不按名称正则、不写死服务地址。

### 3. 页面统一分区结构

配置页按数据流顺序分卡（每张 Card 一个环节），参考自定义素材：

1. 素材/输入（FileDrop + 缩略图条，多选、可删、FileList 必须同步快照成 `File[]`);
2. 分析（可选，视觉模型产出描述）;
3. 文案与标题（AI 创作 / 固定文案；主题即标题）;
4. 画面来源（模板或工作流，选中后折叠成摘要卡）;
5. 配音（服务下拉 → 按类型分流：comfy 出工作流包+参数表单；Liber Speech 出音色库；edge/第三方出服务音色列表+刷新）;
6. 背景音乐/画幅等收尾参数。

通用控件：`NumberStepper`（数值，含 float)、`WorkflowInputs`(manifest 参数，options_from 出模型/节点下拉）、`Segmented`（模式切换）、`Field`（标签+提示）。

### 4. 流水线侧的统一约定

- 任务参数进 `job.params`,Provider 在 runner 里用 `pick_provider` 按能力取（带请求里的指定 id);
- Comfy 链路统一走 `run_workflow_pack`，取件按类型：`extract_files`（文件）/ `extract_texts`（文本）;
- 等待超时统一读 `comfy_wait_timeout_seconds`；超时/取消时 Comfy 侧自动 `cancel_prompt`，不留孤儿任务;
- 产物 meta 记全：模板、画面/配音/分析工作流、模型、音色、BGM、帧数、耗时——作品预览页（MediaLightbox）按 `META_LABELS` 展示;
- 兼容旧任务：新增 params 键全部可选，旧结构要能跑。

### 5. 验证与收尾

- 后端：venv 导入冒烟 + 关键函数单测级验证（如公式不超界）;
- 前端：`npx tsc -b` + 浏览器实测（注意同步盘上 Vite watcher 已开轮询；页面没变就先硬刷新）;
- 合规：移植的文件在 `THIRD_PARTY_NOTICES.md` 逐项登记（Apache-2.0 项目保留 NOTICE);
- 文档：`docs/使用文档.md` 对应功能节同步更新。

## 迁移 checklist（每个功能过一遍）

- [ ] 参考链路图 + 功能对照表
- [ ] Provider 能力声明齐全（缺能力先加注册表）
- [ ] 工作流包 capability 用规范词表
- [ ] 页面分区结构 + 服务感知控件（配音/模型/包）
- [ ] 流水线：参数注入、超时、取消清理、meta 完整
- [ ] tsc + 冒烟 + 浏览器实测
- [ ] 合规登记 + 使用文档更新
