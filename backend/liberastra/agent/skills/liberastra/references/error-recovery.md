# 任务失败与恢复

## 常见错误

| 错误 | 处理 |
|------|------|
| 没有可用服务商 | 告诉用户去「服务提供方」启用对应能力的服务商，不要重试 |
| 工作流包不存在 | 先 `list_workflows`，用返回的包名重试一次 |
| 资产 id 不存在或不属于当前用户 | 用 `list_assets` 重新确认 id |
| ComfyUI 连接失败 | 提示检查 ComfyUI 地址和是否启动；不要连续重试 |
| 任务失败 | 原样转述 `error`，建议换模型、换工作流或降低分辨率 |
| 等待超时 | 告诉用户去任务中心查看，任务可能仍在运行 |

## 重试规则

- 参数错误只重试一次，修参数后再提交。
- 连接类错误不要连续重试，先让用户检查服务。
- 不要为同一个失败任务伪造成功结果或 asset id。

## 任务中心

生成任务异步执行。返回的 `job_id` 可在任务中心查看进度和输出；消息里也会显示可预览的资产。
