# 服务商与画布菜单（定稿）

本文取代上一版「通用表单」实现。界面按此开发，测试按文末接缝验收。

## 服务商

- 同一类型可以保存多份配置。左侧列出每一份实例，不按类型去重。
- 未进入某一份配置时，右侧是服务商卡片。已启用在上，未启用在下。卡片含名称、一句说明和开关。
- 进入某一份配置后：API Key、代理地址、连通性检查（模型下拉 + 检查）、模型列表。模型按 全部 / 对话 / 图片 / 视频 分栏，每行有名称、模型 ID、能力标记和独立开关。
- 火山方舟 Seedance 2.5（`doubao-seedance-2-5-260628`）的能力是：文生视频 `t2v`、首帧生视频 `i2v_first`、首尾帧视频 `i2v_flf`、参考生视频 `v2v_ref`。首帧与参考互斥；首尾帧比例锁定 `adaptive`。这些能力分别进入同名画布功能，不另造一组节点。

## 画布功能菜单

出厂项按工作流包的真实用途生成，不再把不同包压成同一个粗能力。

| 简称 | 细分能力 | 对应包 |
| --- | --- | --- |
| 文生图 | t2i | t2i / flux / qwen 文生图 |
| 单图编辑 | i2i_single | 单图编辑包 |
| 多图编辑 | i2i_multi | 名称含 multi 的编辑包 |
| 局部重绘 | inpaint | 名称含 inpaint |
| 摄影调色 | color_grade | `qwen_edit_2511_color_grade` |
| 放大修复 | upscale | upscale |
| 画面分析 | analysis | 图像分析包 |
| 文生视频 | t2v | 文生视频包 |
| 首帧生视频 | i2v_first | 普通图生视频包 |
| 首尾帧视频 | i2v_flf | 模型能力；双图且不是环绕/参考时 |
| 参考生视频 | v2v_ref | 名称含 ref |
| 360全景 | i2v_orbit | `minimax_h3_orbit` |
| 图生增强 | i2v_enhance | 图生视频 enhancer |
| 文生增强 | t2v_enhance | 文生视频 enhancer |
| 数字人口播 | avatar | avatar |
| 动作迁移 | motion | motion |
| 视频分析 | video_analysis | 视频分析包 |
| 文字转语音 | tts | 语音合成 |
| 语音识别 | asr | 语音识别 |

越狱包与官方包属于同一功能，不单独占菜单。

菜单设置按语音 / 图像 / 视频分成卡片，而不是一排标签单元格。每张卡片可改简称、删除。可以新增一项并选择细分能力。绑定方式为自动或手动。手动时列出该能力下的工作流包和模型，勾选才生效。

## 画布

- 功能菜单在画布上部中央展开：三个横排分类，点开后是横排功能名。不使用添加节点的分段控件，分类文字保持横排。
- 添加节点只负责输入、输出、拼接。
- 选择文生图时补建一个文本输入并连线。已有输入不删除。
- 属性面板保留提示词的 LLM 优化和「强制执行」。
- 画布不再使用「画布分组」：工具坞去掉分组入口，工作流包页去掉分组页，节点上不再出现所属分组下拉。

## 测试接缝

- `pack_sub_capability`：环绕包是 `i2v_orbit`，调色包是 `color_grade`，重绘包是 `inpaint`。
- `default_canvas_menu`：包含「360全景」和「摄影调色」。
- `media_slots("t2i")`：包含必填文本槽。
- `targets_for_menu_item`：手动模式只返回勾选的目标。
- `PUT /api/v1/canvases/menu`：可以追加新菜单项。
- 同一 `volcengine_ark` 类型可以创建两份配置。
