快速开始 ​

LiberAstra 是本机的编排界面。出图、出声、出视频都交给已配置的外部服务，本机不内置模型。

第一次跑起来需要四步：启动编排台、接服务、导入工作流包、开始创作。

1. 启动 ​

在仓库根目录：

bash
cp .env.example .env
docker compose up -d --build

打开 http://localhost:8000。首次进入会引导创建管理员账号。更多安装方式见 安装 / 下载。

本机运行与开发模式 ​

生产环境只启动后端。先在 frontend 执行一次 npm run build，再在 backend 执行：

powershell
uv run astra serve --reload

浏览器打开 http://127.0.0.1:8000/，接口与打包页面同端口。

改界面时另开前端开发服务器 http://127.0.0.1:5173/；页面里的 /api 转到 8000。8000 上的页面要重新 npm run build 才会跟上源码。

一个账号可多浏览器同时登录；每张令牌约 12 小时，过期后重新登录。

安装包、Ollama、ComfyUI 和各工作流模型的下载地址见 部署相关资源下载。

2. 接入服务提供方 ​

进入「设置 → 服务提供方」，按你实际运行的服务添加：

场景类型地址示例
局域网 ComfyUIComfyUIhttp://192.168.1.20:8188
本地 OllamaOllamahttp://localhost:11434
Liber SpeechLiber Speech APIhttp://localhost:5555
在线 TTS本地（微软 Edge TTS）零配置
OpenAI 兼容 LLMOpenAI 兼容服务http://localhost:8000/v1

只列出已启用、且具备对应能力的 Provider。模型不在 LiberAstra 内运行。

3. 导入工作流包 ​

图像 / 视频 / ComfyUI 语音任务需要工作流包。进入「设置 → 工作流包」，可以导入：

  • LiberAstra 工作流包
  • ComfyUI API Format
  • 含 nodes / links 的画布 JSON（自动转换）

内置包（如 qwen_image_21、flux3_klein、minimax_h3_avatar）随应用分发；同名用户包会覆盖内置包。

4. 开始创作 ​

回到「总览」指挥台，写一句创作意图，选择图像、视频或语音，进入对应工作室。也可以直接从左侧菜单进入：

  • 图像：文生图、图生图与编辑、深度图
  • 视频：快速创作、数字人口播、图生视频、动作迁移、自定义素材
  • 语音：文字转语音、语音转文字、换音
  • 工具：图片拼接、视频拼接、音频拼接、图片增强、视频增强
  • 画布：节点、绑定、导演台与运行

任务会进入任务中心，产物回到资产库。每个任务都保留 Provider、工作流与参数。

先搞清三层：服务提供方 → 工作流包 → 模型文件 ​

界面上常同时出现「服务 / Provider」「工作流包」「主模型 / 文本编码器 / VAE」等下拉，含义不同：

层在哪选决定什么不决定什么
服务提供方（Provider）设置 → 服务提供方；各功能页的「图像/视频/语音服务」请求发到哪台机器（地址、密钥、启用）用哪套模型、哪张计算图
工作流包设置 → 工作流包；各功能页的「工作流 / 插图工作流 / 视频工作流」等哪张 Comfy 计算图、参数映射、能力（t2i/t2v/i2v/v2v…）、可选 Turbo服务地址
模型文件包选中后，参数区按 manifest 的 options_from 展开这台 Comfy 磁盘上具体哪个权重文件图的结构（由图决定）

因此：

  • 换一台 Comfy → 改 Provider。
  • 换「官方 / 越狱 / 是否提示词增强 / 是否 Turbo」→ 主要靠换包，或同一包里换成套模型文件（见下文套餐表）。
  • 功能页和侧栏「画布」上的功能节点，最终都落到某个工作流包（或云端模型）。Comfy 网页用来导出工作流包；把多个包串成一条流程，用「画布」。
  • 侧栏「工具」里的图片拼接、视频拼接、音频拼接是本机原生工具，不经过 Provider 和工作流包；图片增强、视频增强才需要 ComfyUI 的 upscale / v2v 包。

能力对不上时，下拉会空或提示「无 xxx 工作流包」。快速创作「生成视频」默认只列 capability: t2v 的包；选了登场角色后才会加上 i2v 包。工作流包下拉先显示能力名和包的一句说明，越狱包标「越狱版」；右侧的灯泡会弹出当前包的完整用途说明。

总览 ​

侧栏「总览」是快速入口。上方三张模式卡切换图像、视频、语音：在输入框写一句提示词，点「开始」，会跳到对应功能页（图像 → 文生图，视频 → 快速创作，语音 → 文字转语音），提示词一并带过去。

下方「工具」按图像、视频、语音和工具四组列出常用入口：

  • 图像：文生图、图生图与编辑、深度图生成。
  • 视频：快速创作、图生视频、数字人口播、动作迁移。
  • 语音：文字转语音、语音转文字、换音。
  • 工具：图片拼接、视频拼接、音频拼接、图片增强、视频增强。

入口只是跳转；实际生成仍取决于各功能页选的服务提供方和工作流包。

从资源库选择 ​

图片编辑、图片增强、深度图、视频增强、语音转文字、角色库、图生视频、数字人、动作迁移和自定义素材的上传区下方都有「从资源库选择」。可以直接挑已有的图片、视频或音频，不必重新上传；单选页点一下就带入，多选页勾选后点「确认选择」。选中的素材和本地上传一样出现在缩略图条里，可以逐张移除。

选择后按新上传的文件参与本次任务；原资产不受影响。

小贴士 ​

  • Web、CLI、MCP 和 OpenAI 兼容 /v1 共用同一套任务系统。
  • 模型下载、显存和进程安全由 ComfyUI / Ollama / 语音服务负责。
  • 本地开发：后端 uv run astra serve --reload，前端 npm run dev（5173，代理 /api 到 8000）。
