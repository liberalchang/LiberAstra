作品与任务 ​

LiberAstra 将「PromptField → 任务队列 → 作品（结果）」串联起来：

  1. 在 PromptField 中提交任务
  2. 任务进入队列，可查看状态与日志
  3. 成品进入「作品」区域统一管理（图像 / 视频 / 语音）

实际的模型执行在 ComfyUI / Ollama / 语音服务中完成。
