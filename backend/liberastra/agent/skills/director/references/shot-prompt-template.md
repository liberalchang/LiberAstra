# 分镜与关键帧提示词模板

写提示词时按这个顺序组织，避免遗漏人物一致性和镜头运动约束。

## 分镜提示词

```text
[主题与场景]
{一句话主题}，{时间/天气/环境}，{地点}。

[人物一致性]
{角色名}，{年龄段}，{发型}，{服装}，{体型}，{气质}。
如使用角色节点，写：保持 <Picture 1> 中人物的五官、发型和服装一致。
如使用文本变量，写：角色设定参考 {{input_text_character}}。

[镜头]
{景别：远景/全景/中景/近景/特写}，{机位：平视/俯拍/仰拍/过肩}，
{构图：居中/三分/对称/前景遮挡}，{光影：自然光/侧逆光/霓虹/柔和棚拍}，
{镜头语言：缓慢推近/手持跟随/固定机位/环绕}。

[动作与物理]
{人物正在做什么}，{动作方向}，{衣物/头发/道具的物理反应}，
{画面中必须保持稳定的元素}。

[风格]
{写实电影感/动画/胶片颗粒/赛博朋克/水墨}，{色调}，{画质关键词}。
```

## 关键帧提示词

关键帧数量由第 6 步的选择决定：

- 只生成首帧：每镜 1 张，只写首帧提示词。
- 生成首尾帧：每镜 2 张，写首帧和尾帧提示词。

首帧在分镜提示词后追加：

```text
[首帧] 开场画面，{动作起点}，{人物位置}，{构图}。
[时间点] 0 秒。
```

尾帧在分镜提示词后追加：

```text
[尾帧] 收束画面，{动作终点}，{人物位置}，{构图}。
[时间点] 镜头结束。
[衔接] 与首帧保持同一人物、服装、场景和光线，只改变动作阶段与机位。
```

同一分镜的首尾帧必须共享人物、服装、场景和光线。只生成首帧时不要写尾帧段落。

## 视频提示词

视频节点不要重复整段分镜描述，突出运动和约束：

```text
{主体动作}，{镜头运动}，{时长节奏}。
保持人物外观与首帧一致；不要出现额外人物、文字、水印和突变镜头。
```

目标有两个图片槽（首帧 + 尾帧）时，改成写过渡：

```text
从首帧的{起始状态}自然过渡到尾帧的{结束状态}，{主体动作}，{镜头运动}，{时长节奏}。
保持人物、服装、场景和光线连续；不要出现额外人物、文字、水印和突变镜头。
```

### 参考图分组提示词

首帧模式（合成图一行 N 张）：

```text
这是 {N} 个分镜的首帧合成图，一行 {N} 张，从左到右第 {i} 张对应分镜 {i}。
这张合成图只作参考，不要求视频严格以某一张开始或以某一张结束。
按从左到右的顺序表现：
第 1 张（分镜 1，约 {d} 秒）：{分镜 1 内容}
...
总时长约 {total} 秒。保持人物、服装和场景一致；不要出现分格线、文字、水印。
```

首尾帧模式（合成图 2 行 N 列）：

```text
这是 {N} 个分镜的首尾帧合成图，2 行 {N} 列。
第一行从左到右是分镜 {ids} 的首帧；第二行是对应分镜的尾帧。
每一列上下两张属于同一个分镜，第 {i} 列对应分镜 {i}。
这张合成图只作参考，不要求视频严格以第一行开始、以第二行结束。
按从左到右的顺序表现：
第 1 列（分镜 1，约 {d} 秒）：{分镜 1 内容}
...
总时长约 {total} 秒。保持人物、服装和场景一致；不要出现分格线、文字、水印。
```

## 示例

```text
[主题与场景] 雨夜霓虹街头，一位年轻女侦探撑黑伞停在便利店门口。
[人物一致性] 黑色短发，米色风衣，深色长裤，神情冷静；保持 <Picture 1> 的五官和服装一致。
[镜头] 中景，平视，三分构图，右侧霓虹作前景遮挡，侧逆光，镜头缓慢推近。
[动作与物理] 她收起雨伞，雨水顺着伞骨滴落，风衣下摆被夜风吹动。
[风格] 写实电影感，青橙色调，35mm 胶片颗粒，浅景深。
[视频] 她抬头看向便利店招牌，镜头缓慢推近到面部；保持人物外观与首帧一致。
```

## 检查

- 人物、服装、场景是否在该分镜已生成的关键帧之间保持一致？
- 是否写清景别、机位、光影和运动？
- 是否包含“不要出现”的负面约束？
- 文本引用是否使用 `{{变量名}}`，图片引用是否使用 `<Picture n>`？
