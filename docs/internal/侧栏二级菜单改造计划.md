# 侧栏二级菜单改造计划

> **历史方案（已归档）**：本文记录当时的开发计划与决策，不代表当前实现。当前功能与文档以 `site/docs-src/` 和代码为准；请勿直接按本文实施。


日期：2026-11-02
状态：已实现（2026-11-02）
范围：仅前端侧栏导航；不改路由、页面内容、后端与工作流

## 1. 结论摘要

把现在「8 组 27 项全部平铺」的侧栏改成「一级 9 行 + 右侧浮层二级」：

- 一级项：总览、画布、图像、语音、视频、资源、任务、设置、阅读。
- 「总览」「画布」「任务」为直达项；其余一级项**点击**后向右展开浮层，浮层内放原有子项；悬停只做高亮，不自动打开。
- 桌面端使用右侧浮层；移动端抽屉内退化为手风琴，不依赖 hover。
- 底部工具条里的设置图标移除，设置只保留侧栏这一个入口。
- 现有 27 个功能入口、路由、图标语义、权限与后端全部不变。

设计概念：**设备抽屉（Patch Bay）**。一级是 9 个通道，二级是当前通道抽出的设备条；浮层只在需要时出现，关闭后侧栏恢复成一条安静的仪器列表。它属于「导演监视台」的 Operate 模式，不追求装饰性，只追求扫读与定位。

## 2. 背景与问题

现状（`frontend/src/components/Layout.tsx`）：

- 8 个文字分组标题 + 27 个链接全部纵向铺开，侧栏在 900px 高度下已经需要滚动。
- 分组标题与一级功能名重复（如「图像」标题下再列 4 项），信息密度低。
- 底部工具条另有设置图标，与侧栏「设置」组重复，入口不唯一。
- 参考图 `参考项目/data/功能页参考图.png` 给出的方向是：一级窄栏 + 向右分组浮层。该方向适合桌面工具台，但参考图的留白与浅灰风格偏轻，本项目应沿用现有的高密度、细边框、状态色体系。

目标：

1. 一级菜单稳定在 9 行以内，常用入口保持一眼可见。
2. 所有功能最多 2 次操作可达。
3. 不牺牲键盘操作、明暗主题、中英双语与移动端可用性。
4. 不改变任何页面路由与功能行为。

## 3. 已确认决策

| 决策 | 结论 |
| --- | --- |
| 二级展开方式 | 桌面端右侧浮层；移动端抽屉内手风琴 |
| 二级化范围 | 图像/语音/视频/资源/设置/阅读收进二级；总览、画布、任务保留为直达项 |
| 设置入口 | 移除底部设置图标，侧栏设置组成为唯一入口 |
| 交互方式 | 桌面端点击展开/收起，悬停仅高亮，不自动打开；键盘完整可达 |
| 画布入口 | 升为一级直达项，紧接总览 |
| 任务入口 | 保留为一级直达项 |
| 阅读入口 | 原「开发者」改名为「阅读」，收纳使用文档、API 文档、CLI 文档 |
| 语音命名 | 用户所说「语言」即现有「语音」板块 |
| 路由 | 完全不变，27 个现有入口全部保留 |
| 视觉体系 | 只使用现有 token；不新增颜色、字体、圆角或阴影层级 |

> 说明：已确认「语言」是「语音」的笔误，对应文字转语音、语音转文字、音色库、音乐库。

### 4.3 激活规则

- 直达项：总览按精确路径高亮；画布按 `/canvas` 前缀高亮（含 `/canvas/:id`）；任务按精确路径高亮。
- 分组项：当前路径落在该组任一前缀下时，一级项进入“组内当前页”状态；展开浮层后，具体子项再加一层实底高亮。
- `/guide` 归入「阅读」；`/settings/*` 归入「设置」。
- 「服务提供方」只在正好 `/settings` 时高亮；`/settings/system` 等页面不应把「服务提供方」一起点亮（沿用现有 `end` 语义）。
- `/docs` 是 SPA 之外的外链，不参与一级激活匹配；当前页面不会因为它而误高亮。

## 5. 交互规格

### 5.1 桌面展开态（≥ 768px，侧栏 240px）

- 一级行高 40px，左图标 16px，右侧展开标记 14px；只有分组项显示箭头，直达项不显示。
- 点击一级项展开/收起；悬停只改变行底色，不自动打开浮层。点击不会导航，因为一级项本身没有页面。
- 同一时间只允许一个浮层打开；点击另一个一级项时，关闭旧浮层并打开新的。
- 浮层打开时，一级项保持 hover/展开底色；若该组包含当前页，一级项使用更浅的主色底。
- 浮层打开后保持展开，直到再次点击该一级项、点击外部、按 Escape、路由变化、窗口 resize、导航区滚动或侧栏折叠状态切换。
- 浮层内点击任意子项：导航并关闭浮层；点击当前已激活的子项也关闭。
- 浮层不是模态弹窗：没有遮罩、不锁定页面滚动、不抢焦点。

> 选择点击而非悬停：侧栏紧邻主内容，悬停自动展开容易在鼠标移向画布时挡住内容；点击更可预测，也与参考图的箭头语义一致。悬停预览保留为后续可选增强，默认关闭。

### 5.2 桌面折叠态（64px）

- 一级项变成 40×40 的居中图标；直达项用 `title` 和无障碍标签补全名称。
- 分组项点击/键盘展开右侧浮层；悬停只高亮图标，不自动打开；浮层顶部显示组名与小图标，避免只看到图标时失去上下文。
- 折叠状态下浮层宽度、内容、激活态与展开态一致。
- 折叠/展开切换时立即关闭浮层，避免位置错乱。

### 5.3 移动端（< 768px）

- 侧栏仍是现有抽屉；抽屉内不使用右侧浮层，改为侧栏内手风琴。
- 点击一级项展开/收起子项；同一时间只展开一组。
- 抽屉打开时，当前页面所属分组默认展开；直达项保持普通行。
- 点击子项后导航并关闭抽屉。
- 手风琴展开不改变抽屉宽度，内容在侧栏内滚动；底部工具条隐藏“收起侧栏”按钮（抽屉内该状态无意义）。

### 5.4 键盘与焦点

采用 WAI-ARIA 的 disclosure（展开/收起）模式，不使用 `role="menu"`，保留链接语义：

- Tab：依次经过一级项；浮层关闭时，子项不在 Tab 序列里。
- Enter / Space：展开或收起当前一级项，焦点留在一级项上。
- ArrowRight / ArrowDown：展开并聚焦浮层第一个子项。
- 浮层内 ArrowDown / ArrowUp：在子项间移动；Home / End：第一个 / 最后一个。
- ArrowLeft / Escape：关闭浮层并把焦点还给一级项。
- Tab 从浮层最后一个子项移出时，焦点进入下一个一级项，浮层关闭。
- 浮层在 DOM 顺序中紧跟一级项，因此 Tab / Shift+Tab 可以自然进出，不需要手动搬运焦点或焦点陷阱。
- 一级项使用 `aria-expanded`；展开时提供 `aria-controls` 指向浮层。
- 子项使用路由自身的 `aria-current="page"`；外链使用 `aria-label` 说明新窗口。
- 所有可交互元素保留 2px `focus-visible` 主色光环；不使用 `:focus` 代替。

### 5.5 状态机

```text
closed
  ├─ click / Enter / Space / ArrowRight ──> open
  └─ 直达项 click ──> navigate

open(A)
  ├─ click(B) ──> open(B)
  ├─ click(一级项) / Escape / 点击外部 ──> closed
  ├─ 点击子项 / 路由变化 ──> navigate + closed
  └─ resize / 导航区滚动 / 折叠切换 ──> closed
```

移动端：

```text
closed ──tap 一级项──> open（同时关闭其他组）
open   ──tap 一级项──> closed
open   ──tap 子项──> navigate + 关闭抽屉
抽屉打开时：当前组默认 open
```

## 6. 视觉规格

### 6.1 浮层

- 位置：侧栏右边缘外 8px；顶部与一级项顶部对齐并上移 6px。
- 宽度：288px；高度：内容自适应，最大 `100vh - 24px`，超出时内部滚动。
- 视口碰撞：下方空间不足时向上平移；仍不足时顶部贴 12px，内部滚动。
- 表面：`bg-card` + 1px `border-border` + `rounded-2xl`（16px）+ `shadow-lg`。
  - 阴影只在浮层打开时出现，符合 Flat-By-Default；不使用 `shadow-2xl`（留给弹窗）。
- 内边距：6px；子项高 36px；子项圆角 8px。
- 浮层头部：高 36px，12px 次级文字 + 14px 组图标，`sticky top-0 bg-card`，长浮层滚动时保留上下文。
- 小节标题：11px、`text-muted-foreground`、`px-2.5 pb-1 pt-2`；小节之间用 1px 分隔线。
- 浮层滚动条复用现有 `.nav-scroll` 样式。

### 6.2 一级项与激活态

| 状态 | 样式 |
| --- | --- |
| 默认 | `text-foreground/85`，透明底 |
| hover / 浮层打开（非当前组） | `bg-foreground/6` |
| 组内包含当前页（浮层关闭） | `bg-primary/10 text-primary dark:text-[#c4b5fd]` |
| 组内包含当前页且浮层打开 | `bg-primary/15 text-primary dark:text-[#c4b5fd]` |
| 直达项当前页 | `bg-primary/15 text-primary dark:text-[#c4b5fd]`，沿用现有 `navClass` |
| 浮层子项当前页 | `bg-primary/15 font-medium text-primary dark:text-[#c4b5fd]` |

- 一级项“组内当前页”用比子项更浅的主色底，避免侧栏与浮层同时出现两块同等强度的紫色，守住 One Voice Rule。
- 子项 hover：`bg-foreground/6`；当前子项 hover：`bg-primary/20`。
- 不新增彩色左边条、粗边框或装饰性渐变。

### 6.3 图标与文字

- 一级图标 16px，子项图标 16px，展开箭头 14px，外链图标 12px。
- 一级文字 14px / 常规；当前组与当前子项 500 字重。
- 中英文都使用现有系统字栈；不引入第二字体。
- 英文标签在 288px 内保持单行；超出时 `truncate` 并提供 `title`，不换行撑高行高。
- 浮层头部与一级项图标语义不重复：语音一级用 `Headphones`，文字转语音子项用 `AudioLines`；视频一级用 `Video`，快速创作用 `Clapperboard`。

### 6.4 动效

- 浮层：`opacity 0 → 1` + `translateX(-4px) → 0`，140ms ease-out。
- 展开箭头：旋转 90°，150ms。
- 移动端手风琴：高度/透明度 160ms；不做大幅位移。
- `prefers-reduced-motion: reduce` 时全部改为立即切换，不保留位移与旋转动画。

### 6.5 层级

- 浮层 `z-40`：高于主内容，低于 Lightbox/对话框的 `z-50`。
- 浮层使用 `position: fixed` 渲染在一级项之后；固定定位不受非 `transform` 祖先的 `overflow-y-auto` 裁剪，同时保留 DOM 顺序，Tab 可自然从一级项进入子项、再从最后一项进入下一个一级项。
- 若后续出现祖先 `transform` / `filter` 导致固定定位被裁剪，再切换为 Portal，并补显式 Tab 焦点管理（作为备选，不是默认实现）。
- 不添加遮罩层，不改变页面滚动。

## 7. 可访问性

- 语义：`<nav aria-label="主导航">`；一级项用 `<button type="button">`，子项用 `<NavLink>` / `<a>`。
- 展开状态：`aria-expanded`、`aria-controls`；浮层容器用 `role="group"` + `aria-label={组名}`。
- 当前页：`NavLink` 自动输出 `aria-current="page"`；外链用 `aria-label` 补充“在新窗口打开”。
- 键盘：完整支持第 5.4 节；不设置焦点陷阱，Tab 可以自然离开。
- 触屏：所有功能都能通过点击完成，hover 只是增强，不是唯一路径。
- 目标尺寸：一级行 40px、子项 36px，满足现有 40px 图标钮与导航密度约定。
- 对比度：继续使用 `primary` / `muted-foreground` / `border` token；暗色主色文字沿用现有 `#c4b5fd` 例外，不新增硬编码色。
- 缩放：200% 缩放下浮层不溢出视口，文字不截断关键信息（必要时用 `title` 兜底）。

### 8.2 数据模型

```ts
export type NavLeaf = {
  to: string;
  labelKey: string;
  icon: NavIconKey;
  end?: boolean;
  href?: string;      // 外链，例如 /docs
  external?: boolean;
};

export type NavSection = {
  labelKey?: string;  // 视频的「生成」「素材与模板」
  items: NavLeaf[];
};

export type NavEntry =
  | { kind: "link"; id: string; labelKey: string; icon: NavIconKey; to: string; end?: boolean }
  | { kind: "group"; id: string; labelKey: string; icon: NavIconKey; sections: NavSection[]; match: string[] };

export const NAV_ENTRIES: NavEntry[] = [/* 9 个一级项，顺序见 4.1 */];
```

- `match` 显式列出前缀，避免从子项推导时漏掉 `/canvas/:id`。
- `isLeafActive` 统一处理 `end` 与子路径；`isGroupActive` 用 `pathname === prefix || pathname.startsWith(prefix + "/")`。
- `activeGroupId(pathname)` 返回当前页所属的组 id；直达项返回 `null`，供移动端默认展开与父级高亮使用。

### 8.3 组件职责

`SidebarNav`：

- 接收 `mini`、`mobile`、`onNavigate`。
- 维护 `openId: string | null`；桌面初始 `null`，移动端初始为当前组。
- 路由变化、`mini` 变化时关闭浮层。
- 桌面：渲染一级行；分组项展开时渲染 `<NavFlyout anchor={buttonRef}>`。
- 移动：不使用浮层，分组项展开时在同一行下方渲染 `<ul>` 手风琴。
- 点击子项统一调用 `onNavigate`，由 `Layout` 关闭移动抽屉。

`NavFlyout`：

- 渲染在一级项之后的同一 DOM 容器中，使用 `position: fixed`；不做 Portal。
- `useLayoutEffect` 读取锚点 `getBoundingClientRect()`，计算 `left/top`，并做上下翻转与视口夹取。
- 监听 `pointerdown`（点击外部）、`keydown`（Escape / 方向键）、`resize`、导航区 `scroll`。
- 不做指针离开自动关闭；浮层由点击一级项、Escape、外部点击或路由变化关闭。
- 子项渲染 `NavLink` 或外链 `<a>`，并复用现有 `navClass` 的密度与 focus ring。

`Layout`：

- 删除第 46–110 行的 `NAV_GROUPS` 常量与第 157–197 行的内联渲染。
- 桌面：`<SidebarNav mini={collapsed} />`。
- 移动抽屉：`<SidebarNav mini={false} mobile onNavigate={() => setOpen(false)} />`。
- 底部工具条移除设置按钮；清理不再使用的 `Settings` 等图标 import。

## 11. 风险与备选

| 风险 | 影响 | 缓解 |
| --- | --- | --- |
| 悬停误触/浮层遮挡 | 鼠标移向主内容时浮层挡住画布 | 默认点击展开，悬停不自动打开；点击外部即关 |
| 切换分类多一次点击 | 比悬停慢一拍 | 9 个一级项，点击成本可接受；如确需速度，可开启默认关闭的悬停预览 |
| 侧栏 `overflow-y-auto` 裁剪浮层 | 浮层被截断 | 使用 `position: fixed`，不受非 `transform` 祖先的 overflow 裁剪；极端情况再改 Portal + 显式 Tab 管理 |
| 英文标签过长 | 浮层撑宽或换行 | 288px 固定宽 + `truncate` + `title`；中英双轮检查 |
| 键盘不可达 | 无障碍回退 | disclosure 模式；焦点归还；逐项键盘验收 |
| 移动端无 hover | 浮层交互不适合触屏 | 抽屉内手风琴，点击展开 |
| 设置入口唯一后难找 | 用户找不到系统设置 | 设置保留一级行；浮层四项按现有顺序；底部图标移除已确认 |
| 激活态歧义 | 多个入口同时高亮 | 纯函数 + 路由覆盖测试；`end` 语义沿用 |
| 浮层遮挡内容 | 阅读/操作被打断 | 无遮罩、点击外部即关、不锁滚动 |
| 小屏高度不足 | 浮层超出视口 | 最大高度 + 内部滚动 + 上下夹取 |

备选方案：

- **侧栏内手风琴**：实现更简单、移动端一致，但展开后侧栏仍长；本次不采用。
- **分类落地页**：侧栏最简，但每次使用多一次跳转；本次不采用。
- **顶部 mega menu**：与现有左侧监视台布局冲突；本次不采用。
- **命令面板/搜索**：可作为后续增强，不放进本次范围。
