# Speech

Speech has four pages: text to speech, speech to text, voices, and music.

## Text to speech

Choose a TTS provider, model, voice, language, and output format. The voice list follows the provider capability. Local Microsoft Edge TTS needs no setup and outputs mp3; Liber Speech supports cloned voices.

The generated audio appears in history and can be previewed or downloaded. Narration can also be used by Quick Create and avatar video.

## Speech to text

Upload audio or video, choose automatic or explicit language detection, and pick an output type. The default priority is text -> JSON -> SRT -> VTT. History keeps transcripts and subtitle files for download.

## Voice library

Save a reference audio clip, transcript, and tags, or register a cloud `voice_id`. A local reference is used for cloning; a cloud voice_id is returned by the provider. Mark one voice as the default for quick selection.

## Music library

Upload MP3, WAV, M4A, OGG, FLAC, or AAC. Files are added to the library and can be selected as background music in Quick Create. Same-name uploads get a numeric suffix instead of overwriting.
